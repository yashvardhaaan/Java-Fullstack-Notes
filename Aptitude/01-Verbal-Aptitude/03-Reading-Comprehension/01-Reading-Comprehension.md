# Reading Comprehension

## Definition

**Reading Comprehension (RC)** is the ability to read a passage, understand its meaning, analyze the information, and answer questions based on the passage.

It tests:

- Understanding
- Logical reasoning
- Vocabulary in context
- Inference
- Analytical thinking

---

# Reading Comprehension Process

```
Read Passage
      │
      ▼
Understand the Main Idea
      │
      ▼
Identify Important Details
      │
      ▼
Analyze Tone & Purpose
      │
      ▼
Draw Inferences
      │
      ▼
Answer Questions
```

# Main Idea Questions

These ask for the central theme of the passage.

Example

```
What is the passage mainly about?
```

### Strategy

- Read the introduction.
- Read the conclusion.
- Identify repeated ideas.
- Ignore minor details.

---

# Detail-Based Questions

Answers are directly stated in the passage.

Example

```
According to the passage,
which of the following is correct?
```

### Strategy

Locate the relevant sentence instead of relying on memory.

---

# Inference Questions

The answer is **not directly written**.

You must conclude using the given information.

Example

```
It can be inferred that...
```

### Strategy

- Use only the passage.
- Do not use personal knowledge.
- Choose the conclusion best supported by the text.

---

# Vocabulary Questions

Meaning of a word based on context.

Example

```
The word "critical" most nearly means...
```

### Strategy

Read the entire sentence before interpreting the word.

---

# Author's Purpose

Why did the author write the passage?

Possible purposes

- Inform
- Explain
- Persuade
- Entertain
- Criticize
- Compare
- Warn
- Describe

---

# True / False Questions

Determine whether a statement is supported by the passage.

Rules

- Use only information given.
- Ignore outside knowledge.
- Read carefully for qualifiers such as:
  - Always
  - Never
  - Only
  - All
  - Some

---

# Summary Questions

Choose the option that best summarizes the passage.

A good summary:

- Covers the main idea
- Includes key points
- Omits unnecessary details
- Does not introduce new information

# Common Mistakes

### 1. Using Personal Knowledge

Wrong

Choosing an answer because you know it is true.

Correct

Choose only what the passage supports.

---

### 2. Reading Too Fast

Skipping important details often leads to incorrect answers.

---

### 3. Ignoring Keywords

Words like

```
Always

Never

Only

Most

Some
```

can completely change the meaning.

---

### 4. Assuming Instead of Inferring

Inference must be supported by evidence in the passage.

---

### 5. Spending Too Much Time

Do not reread the entire passage for every question.

Locate the relevant paragraph.

# GATE 80/20 Summary

✅ Read the **first and last paragraphs carefully**.

✅ Focus on:
- Main Idea
- Inference
- Tone
- Vocabulary in Context

✅ Eliminate options that:
- Add new information.
- Are too extreme (**always**, **never**).
- Contradict the passage.

✅ Base every answer **only on the passage**, not on prior knowledge.
