# Para Jumbles

## Definition

**Para Jumbles** are questions in which a set of sentences is given in a random order. The objective is to arrange them into a coherent and logically connected paragraph.

Unlike Narrative Sequencing, para jumbles are primarily based on the **flow of ideas**, not just chronological order.

---

# Objective

Arrange the given sentences so that the paragraph has:

- Logical flow
- Proper coherence
- Correct sentence connections
- Smooth transitions

---

# Structure of a Paragraph

```
Opening Sentence
        │
        ▼
Supporting Idea
        │
        ▼
Explanation
        │
        ▼
Example / Evidence
        │
        ▼
Conclusion
```

---

# Types of Para Jumbles

```
Para Jumbles
│
├── Independent Sentences
├── Linked Sentences
├── Mandatory Pairs
├── Opening Sentence
└── Closing Sentence
```

---

# Opening Sentence

The first sentence introduces the topic.

### Characteristics

- Introduces the subject
- Does not refer to previous information
- Usually contains the main noun
- Does not begin with connectors

### Good Opening

```
Artificial Intelligence has transformed many industries.
```

---

### Poor Opening

```
However, this technology also has limitations.
```

Reason

```
"However" refers to a previous statement.
```

---

# Closing Sentence

The last sentence usually:

- Summarizes the discussion
- Gives a conclusion
- Presents the final outcome
- Ends the author's argument

Example

```
Therefore, responsible AI development is essential.
```

---

# Mandatory Pairs

Some sentences must appear together.

### Example

A.

```
Riya bought a laptop.
```

B.

```
She started learning Java.
```

Since **She** refers to **Riya**, the order is:

```
A → B
```

---

# Pronoun Reference

A pronoun must refer to a noun introduced earlier.

Incorrect

```
They won the competition.

The students practiced daily.
```

Correct

```
The students practiced daily.

They won the competition.
```

---

# Articles

Words like

```
A

An
```

usually introduce something for the first time.

```
A programmer joined the company.
```

Later sentences may use

```
The programmer
```

because the person has already been introduced.

Example

Correct

```
A scientist made a discovery.

The scientist published the results.
```

---

# Transition Words

Transition words help determine sentence order.

---

## Addition

| Word | Purpose |
|------|----------|
| Also | Adds information |
| Moreover | Strong addition |
| Furthermore | Additional point |
| Besides | Extra information |
| In addition | Continues discussion |

---

## Contrast

| Word | Purpose |
|------|----------|

| But | Contrast |
| Yet | Contrast |

---

## Cause

| Word | Purpose |
|------|----------|

| Since | Gives reason |

---

## Result

| Word | Purpose |
|------|----------|
| Therefore | Result |
| Hence | Result |
| Thus | Result |
| Consequently | Result |

---

## Sequence

| Word | Purpose |
|------|----------|
| First | Beginning |
| Next | Following event |

| Finally | Conclusion |

# Sentence Linking Clues

## Repeated Keywords

Example

Sentence A

```
Cloud Computing provides scalable resources.
```

Sentence B

```
These resources reduce infrastructure costs.
```

The repeated keyword

```
resources
```

links the two sentences.

---

## Pronouns

Pronouns indicate continuation.

```
Rahul solved the problem.

↓

He celebrated.
```

---

## Synonyms

Different words referring to the same concept.

Example

```
Artificial Intelligence

↓

This technology
```

---

## Cause and Effect

```
Heavy rainfall

↓

Flooding
```

The cause should appear before the effect.

---

# Elimination Strategy

When unsure, eliminate impossible openings.

A sentence is **unlikely to be first** if it begins with:

```
However

Therefore

Thus

Moreover

Also

Instead

Yet

Meanwhile
```

because these words require previous context.

---

```
Read All Sentences
```

# Example 1

Arrange the following.

A.

```
Machine learning is a branch of Artificial Intelligence.
```

B.

```
It enables computers to learn from data.
```

C.

```
This capability improves prediction accuracy.
```

### Solution

```
A → B → C
```

Reason

- A introduces the topic.
- B explains Machine Learning.
- C explains the result.

### Solution

# Common Mistakes

## Mistake 1

Choosing a sentence starting with

```
However

Therefore

Thus
```

as the first sentence.

---

## Mistake 2

Ignoring pronoun references.

Incorrect

```
He became successful.

Rohan started a company.
```

Correct

```
Rohan started a company.

He became successful.
```

---

## Mistake 3

Ignoring repeated keywords.

Repeated words often indicate connected sentences.

---

## Mistake 4

Placing examples before explanations.

Correct order

```
Definition

↓

Explanation

↓

Example
```

---

## Mistake 5

Ignoring logical progression.

Ideas should naturally develop from simple to detailed.

---

# GATE 80/20 Summary

✅ Find the **opening sentence** by identifying the topic introduction.

✅ Look for **mandatory pairs** using pronouns, articles, and repeated keywords.

✅ Keep **cause before effect** and **definition before example**.

✅ Sentences beginning with **However**, **Therefore**, **Thus**, or **Moreover** are rarely the opening sentence.

✅ After arranging the paragraph, read it once to ensure a smooth and logical flow.
