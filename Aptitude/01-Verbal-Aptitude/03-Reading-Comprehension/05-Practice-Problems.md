# Common Traps

## Trap 1 — Extreme Words

Be cautious with options containing:

```
Always

Never

Only

Completely

All
```

Unless the passage explicitly states them.

---

## Trap 2 — Outside Knowledge

Choose answers **only** from the passage.

---

## Trap 3 — Partially Correct Options

Some options contain one correct fact but add unsupported information.

Reject such options.

---

## Trap 4 — Similar Wording

The exam may rephrase sentences from the passage.

Focus on the meaning, not exact wording.

---

# Previous Year Question Pattern

Most frequently tested question types:

- Main Idea
- Detail-Based Questions
- Inference
- Vocabulary in Context
- Author's Tone
- Author's Purpose
- Best Title
- True/False Statements
- Summary

# Quick Revision Sheet

| Question Type | Strategy |
|--------------|----------|
| Main Idea | Find the central theme |
| Detail | Locate the exact sentence |
| Inference | Use evidence only |
| Vocabulary | Read surrounding context |
| Tone | Identify the author's attitude |
| Purpose | Determine why the passage was written |
| Summary | Include only key ideas |
