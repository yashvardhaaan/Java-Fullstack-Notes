# Narrative Sequencing

## Definition

**Narrative Sequencing** is the process of arranging sentences or events in the correct chronological or logical order to form a meaningful passage or story.

It tests the ability to identify:

- Logical flow
- Chronological order
- Cause and effect
- Continuity of ideas
- Pronoun references

---

# Basic Structure of a Narrative

```
Beginning
     │
     ▼
Introduction
     │
     ▼
Development
     │
     ▼
Important Event
     │
     ▼
Climax
     │
     ▼
Conclusion
```

Every narrative generally follows this sequence.

# 1. Chronological Order

Events are arranged according to time.

### Example

Incorrect

```
He graduated.

He joined college.

He got a job.
```

Correct

```
He joined college.

He graduated.

He got a job.
```

---

# 2. Logical Order

Ideas should naturally follow one another.

Example

Incorrect

```
She submitted the assignment.

She started writing it.
```

Correct

```
She started writing the assignment.

She submitted it.
```

---

# 3. Cause and Effect

One event causes another.

Structure

```
Cause
   │
   ▼
Effect
```

Example

```
It rained heavily.

↓

The roads were flooded.
```

---

# 4. Process Order

Steps of a process should be arranged correctly.

Example

```
Write code

↓

Compile

↓

Run

↓

Check Output
```

---

# 5. Story Completion

Find the sentence that best completes the passage while maintaining continuity.

# Indicators of Sequence

## Time Indicators

These indicate chronological order.

| Word | Meaning |
|------|---------|
| First | Beginning |
| Initially | At the start |
| Then | Next |
| Afterwards | Later |
| Meanwhile | At the same time |
| Soon | Shortly after |
| Finally | End |
| Eventually | After a long time |

---

## Cause and Effect Indicators

| Cause | Effect |
|--------|--------|
| Because | Therefore |
| Since | Thus |
| As | Hence |
| Due to | Consequently |
| Owing to | As a result |

---

## Addition Indicators

| Word | Purpose |
|------|---------|
| Also | Add information |
| Moreover | Additional point |
| Furthermore | Strong addition |
| Besides | Extra information |
| In addition | Add another point |

---

## Contrast Indicators

| Word | Purpose |
|------|---------|
| But | Contrast |
| However | Opposite idea |
| Although | Concession |
| Yet | Contrast |
| Nevertheless | Unexpected contrast |

---

# Clues for Finding the First Sentence

A good opening sentence usually:

- Introduces the topic.
- Introduces the main character.
- Does not begin with a pronoun without reference.
- Does not begin with connectors like **However**, **Therefore**, or **Meanwhile**.

### Good Opening

```
Riya wanted to learn programming.
```

---

### Poor Opening

```
Therefore she practiced every day.
```

Reason:

```
"Therefore" refers to an earlier idea.
```

---

# Clues for Finding the Last Sentence

The last sentence usually:

- Gives the result.
- Concludes the story.
- Provides a lesson.
- Ends the discussion.

Example

```
She finally became a software engineer.
```

---

# Pronoun Reference

Pronouns must refer to a previously introduced noun.

Incorrect Order

```
He became successful.

Rahul started a business.
```

Correct Order

```
Rahul started a business.

He became successful.
```

---

# Transition Words

These help connect ideas smoothly.

| Transition | Usage |
|------------|-------|
| First | Beginning |
| Next | Sequence |
| Then | Next event |
| Later | Future event |
| Finally | Conclusion |
| Therefore | Result |
| However | Contrast |
| Consequently | Result |
| Meanwhile | Simultaneous event |
| Eventually | Final outcome |

# Common Mistakes

## Mistake 1

Ignoring pronoun references.

Incorrect

```
He won the competition.

Aman participated.
```

Correct

```
Aman participated.

He won the competition.
```

---

## Mistake 2

Ignoring time sequence.

Incorrect

```
The cake was baked.

The ingredients were mixed.
```

Correct

```
The ingredients were mixed.

The cake was baked.
```

---

## Mistake 3

Placing conclusion in the middle.

Every narrative should end with the outcome or conclusion.

---

## Mistake 4

Starting with connecting words.

Avoid starting with:

```
However

Therefore

Hence

Meanwhile
```

unless the previous context is already provided.

# Practice Questions

## Q1

Arrange the following sentences.

A.

```
He submitted the application.
```

B.

```
He got the job.
```

C.

```
He attended the interview.
```

D.

```
He applied online.
```

### Correct Order

```
D → A → C → B
```

# GATE 80/20 Summary

✅ Find the **opening sentence** first.

✅ Look for **pronoun references** to connect sentences.

✅ Use **time indicators** and **transition words** to determine order.

✅ Keep **cause before effect**.

✅ Place **conclusions and outcomes** at the end of the sequence.
