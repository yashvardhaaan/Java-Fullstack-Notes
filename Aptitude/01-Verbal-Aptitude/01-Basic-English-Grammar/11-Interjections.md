# Why Learn Interjections?

Interjections are words that express **sudden emotions or feelings**.

They make communication more expressive and natural.

Compare these sentences.

Without Interjection

```
You won the competition.
```

With Interjection

```
Hurrah! You won the competition.
```

The second sentence expresses excitement.

---

# What is an Interjection?

An **Interjection** is a word or short phrase that expresses

- Joy
- Surprise
- Pain
- Sorrow
- Anger
- Greeting
- Approval
- Disapproval

It is usually followed by an **exclamation mark (!)**.

---

# Examples

```
Wow!

Hurrah!

Oops!

Oh!

Alas!

Bravo!
```

---

# Characteristics of Interjections

✔ Express sudden emotions

✔ Usually stand alone

✔ Often followed by **!**

✔ Do not affect sentence grammar

# Interjection vs Exclamation

### Interjection

A word expressing emotion.

Example

```
Wow!
```

---

### Exclamation

A complete sentence expressing strong emotion.

Example

```
What a beautiful day!
```

---

# Interjection Placement

An interjection is usually placed at the **beginning** of a sentence.

Example

```
Wow! This view is amazing.
```

It may also appear in the middle or end for conversational effect.

Example

```
You did it, wow!
```

---

# Punctuation Rules

### Rule 1

Use **!** for strong emotions.

```
Hurrah!

Wow!

Bravo!
```

---

### Rule 2

A comma may be used for mild emotions.

```
Oh, I understand now.

Well, let's begin.
```

---

### Rule 3

Avoid excessive punctuation.

Incorrect

```
Wow!!!!!!
```

Better

```
Wow!
```

# Common GATE & Placement Errors

### Incorrect

```
Wow you solved it.
```

Correct

```
Wow! You solved it.
```

---

### Incorrect

```
Alas! We won the match.
```

Correct

```
Hurrah! We won the match.
```

("Alas!" expresses sorrow, not joy.)

---

### Incorrect

```
Bravo! She failed the exam.
```

Correct

```
Oh no! She failed the exam.
```

# Interview Corner

### Q1. What is an interjection?

An interjection is a word or short phrase that expresses a sudden emotion or feeling.

---

### Q2. Is an interjection a part of the sentence grammar?

No. An interjection is generally independent of the sentence's grammatical structure.

---

### Q3. Why are interjections usually followed by an exclamation mark?

Because they express strong emotions such as surprise, joy, pain, or sorrow.
