# Why Learn Tenses?

Tenses tell us **when** an action happens.

Without correct tenses, sentences become confusing.

Example

Incorrect

```
Yesterday I go to college.
```

Correct

```
Yesterday I went to college.
```

Tenses are one of the most frequently tested grammar topics in competitive exams.

---

# What is a Tense?

A **Tense** indicates the **time of an action or state**.

It tells whether the action happens

- In the Present
- In the Past
- In the Future

# Present Tense

## 1. Simple Present

### Structure

```
Subject

+

V1 / V1+s/es

+

Object
```

---

### Uses

- Daily routine
- Habits
- Universal truths
- Facts

---

### Examples

```
She studies every day.

The sun rises in the east.

I drink coffee every morning.
```

---

### Signal Words

```
Always

Usually

Often

Sometimes

Every day

Never
```

---

# 2. Present Continuous

### Structure

```
Subject

+

am/is/are

+

V-ing

+

Object
```

---

### Uses

- Action happening now
- Temporary situations

---

### Examples

```

```

---

### Signal Words

```
Now

Right now

Currently

At present
```

# 3. Present Perfect

### Structure

```
Subject

+

has/have

+

V3

+

Object
```

---

### Uses

- Completed action with present relevance
- Experience
- Recent events

---

### Examples

```
She has completed the project.

I have visited Delhi.

They have finished lunch.
```

---

### Signal Words

```
Already

Yet

Just

Ever

Never

Since

For
```

---

# 4. Present Perfect Continuous

### Structure

```
Subject

+

has/have been

+

V-ing

+

Since/For
```

---

### Uses

Actions that started in the past and are still continuing.

---

### Examples

```
I have been studying for three hours.

She has been working since morning.
```

+

V-ing

---

# 7. Past Perfect

### Structure

```
Subject

+

had

+

V3
```

---

### Uses

Action completed before another past action.

---

### Examples

```

The train had departed.
```

---

### Structure

```
Subject

+

had been

+

V-ing
```

---

### Uses

Action continuing before another action in the past.

---

### Examples

```

They had been waiting since morning.
```

# Since vs For

### Since

Used for a **starting point**.

Examples

```
Since 2023

Since Monday

Since morning
```

---

### For

Used for a **duration**.

Examples

```
For 2 hours

For 5 years

For 10 days
```

# Interview Corner

### Q1. How many tenses are there in English?

There are **3 main tenses** (Present, Past, Future) and **12 commonly taught tense forms**.

---

### Q2. What is the difference between the Simple Past and the Present Perfect?

- **Simple Past** is used for completed actions at a specific time in the past.
- **Present Perfect** is used for completed actions that have a connection to the present.

Example:

```
I visited Delhi last year.

(Simple Past)
```

```
I have visited Delhi.

(Present Perfect)
```

---

### Q3. What is the difference between "since" and "for"?

- **Since** → Starting point
- **For** → Duration

Examples:

```
Since Monday

For three days
```
