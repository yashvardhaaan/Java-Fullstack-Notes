# What is Direct Speech?

**Direct Speech** reports the **exact words** spoken by someone.

It is enclosed within **quotation marks (" ")**.

### Structure

```
Reporting Clause + "Reported Speech"
```

### Examples

```
Rahul said, "I am busy."

She said, "I will help you."

The teacher said, "Work hard."
```

---

# What is Indirect Speech?

**Indirect Speech** reports the meaning of what someone said without using the exact words.

Quotation marks are removed.

### Structure

```
Subject + Reporting Verb + That + Reported Clause
```

### Examples

Direct

```
Rahul said, "I am busy."
```

Indirect

```
Rahul said that he was busy.
```

---

# Direct vs Indirect Speech

| Direct Speech | Indirect Speech |
|---------------|-----------------|
| Uses quotation marks | No quotation marks |
| Exact words | Reported meaning |
| "I am happy." | He said that he was happy. |

# General Rules for Conversion

When converting Direct to Indirect Speech, check:

✔ Reporting Verb

✔ Tense

✔ Pronouns

✔ Time Expressions

✔ Sentence Type

---

# Rule 1: Change of Tense

If the **reporting verb is in the past**, the tense usually shifts back.

| Direct | Indirect |
|---------|-----------|
| Simple Present | Simple Past |
| Present Continuous | Past Continuous |
| Present Perfect | Past Perfect |
| Simple Past | Past Perfect |
| Will | Would |
| Can | Could |
| May | Might |
| Shall | Should / Would |

---

## Examples

### Simple Present → Simple Past

Direct

```
He said, "I work hard."
```

Indirect

```
He said that he worked hard.
```

---

### Present Continuous → Past Continuous

Direct

```
She said, "I am studying."
```

Indirect

```
She said that she was studying.
```

---

### Present Perfect → Past Perfect

Direct

```
He said, "I have finished."
```

Indirect

```
He said that he had finished.
```

---

### Simple Past → Past Perfect

Direct

```
She said, "I bought a car."
```

Indirect

```
She said that she had bought a car.
```

---

### Will → Would

Direct

```
He said, "I will come."
```

Indirect

```
He said that he would come.
```

---

# Rule 2: Pronoun Changes

Pronouns change according to the speaker and listener.

| Direct | Indirect |
|---------|-----------|
| I | He / She |
| Me | Him / Her |
| My | His / Her |
| We | They |
| Our | Their |
| You | I / We / He / She / They (depends on context) |

---

### Example

Direct

```
Rahul said, "I like cricket."
```

Indirect

```
Rahul said that he liked cricket.
```

---

# Rule 3: Time and Place Changes

Certain words change when reporting speech.

| Direct | Indirect |
|----------|-----------|
| Now | Then |
| Today | That day |
| Tomorrow | The next day |
| Yesterday | The previous day |
| Tonight | That night |
| Ago | Before |
| Here | There |
| This | That |
| These | Those |
| Next Week | The following week |
| Last Month | The previous month |

---

### Examples

Direct

```
She said, "I will come tomorrow."
```

Indirect

```
She said that she would come the next day.
```

---

# Rule 4: No Tense Change

Do **not** change the tense when:

### Reporting verb is in Present or Future.

Example

Direct

```
Rahul says, "I am busy."
```

Indirect

```
Rahul says that he is busy.
```

---

### Universal Truth

Direct

```
The teacher said, "The Earth revolves around the Sun."
```

Indirect

```
The teacher said that the Earth revolves around the Sun.
```

# 1. Assertive Sentences

Reporting Verb

```
Said

↓

Said That
```

Example

Direct

```
He said, "I am tired."
```

Indirect

```
He said that he was tired.
```

---

# 2. Interrogative Sentences

Remove the question form.

Use:

- Asked
- Inquired
- Wanted to know

---

### Yes/No Questions

Use **if** or **whether**.

Direct

```
He said, "Are you ready?"
```

Indirect

```
He asked if I was ready.
```

---

### WH Questions

Keep the WH word.

Direct

```
She said, "Where do you live?"
```

Indirect

```
She asked where I lived.
```

---

# 3. Imperative Sentences

Use verbs such as

- Ordered
- Requested
- Advised
- Suggested
- Told
- Asked

Structure

```
Reporting Verb

+

To + Verb
```

---

Example

Direct

```
The teacher said, "Study regularly."
```

Indirect

```
The teacher advised us to study regularly.
```

---

### Negative Imperative

Structure

```
Not to + Verb
```

Example

Direct

```
He said, "Do not run."
```

Indirect

```
He advised me not to run.
```

---

# 4. Exclamatory Sentences

Use verbs like

- Exclaimed with joy
- Exclaimed with sorrow
- Exclaimed with surprise

Remove the exclamation mark.

---

Example

Direct

```
She said, "What a beautiful flower!"
```

Indirect

```
She exclaimed with admiration that it was a beautiful flower.
```

---

# 5. Optative Sentences

Express wishes or prayers.

Use

- Wished
- Prayed

---

Example

Direct

```
He said, "May you succeed!"
```

Indirect

```
He wished that I might succeed.
```

# Interview Corner

### Q1. What is the difference between Direct and Indirect Speech?

- **Direct Speech** uses the speaker's exact words inside quotation marks.
- **Indirect Speech** reports the meaning without quotation marks.

---

### Q2. When is the tense **not** changed in Indirect Speech?

- When the reporting verb is in the **present or future tense**.
- When the reported statement expresses a **universal truth**.

---

### Q3. What is used for Yes/No questions in Indirect Speech?

Use **if** or **whether**.

Example

```
Direct:
He said, "Are you coming?"

Indirect:
He asked if I was coming.
```
