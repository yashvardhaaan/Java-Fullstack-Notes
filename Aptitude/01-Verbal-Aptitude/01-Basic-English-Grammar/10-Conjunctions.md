# Why Learn Conjunctions?

Conjunctions connect words, phrases, or sentences.

Without conjunctions, writing becomes repetitive.

Example

Without conjunction

```
Rahul studied hard.

Rahul passed the exam.
```

With conjunction

```
Rahul studied hard, so he passed the exam.
```

Conjunctions improve

- Sentence flow
- Clarity
- Logical connection

They are frequently tested in

- Error Spotting
- Fill in the Blanks
- Sentence Correction
- Reading Comprehension

---

# What is a Conjunction?

A **Conjunction** is a word that joins

- Words
- Phrases
- Clauses
- Sentences

---

# Examples

```
Rahul and Amit are friends.

She was tired but she finished the work.

Study hard because exams are near.
```

# 1. Coordinating Conjunctions

These join **equal grammatical units**.

Examples

- Word + Word
- Phrase + Phrase
- Clause + Clause

---

## The FANBOYS Rule

Remember the acronym

```
FANBOYS
```

| Letter | Conjunction | Meaning |
|---------|-------------|----------|
| F | For | Reason |
| A | And | Addition |
| N | Nor | Negative Addition |
| B | But | Contrast |
| O | Or | Choice |
| Y | Yet | Contrast |
| S | So | Result |

---

## Examples

### And

```
Rahul and Amit are classmates.
```

---

### But

```
She is intelligent but lazy.
```

---

### Or

```
Tea or coffee?
```

---

### So

```
It was raining, so we stayed home.
```

---

### Yet

```
He worked hard, yet he failed.
```

---

### Nor

```
She cannot sing, nor can she dance.
```

---

### For

```
He stayed home, for he was ill.
```

---

# 2. Subordinating Conjunctions

These join a **main clause** with a **dependent clause**.

They show relationships such as

- Time
- Reason
- Condition
- Contrast
- Purpose

---

## Common Subordinating Conjunctions

```
Because

Although

Since

If

Unless

While

When

Before

After

Until

Though

As

Where

Wherever
```

---

## Examples

### Because

```
She succeeded because she worked hard.
```

---

### Although

```
Although it was raining, we played football.
```

---

### If

```
If you study, you will pass.
```

---

### Unless

```
You cannot succeed unless you work hard.
```

---

### While

```
She was reading while I was cooking.
```

---

### Before

```
Wash your hands before eating.
```

---

### After

```
Call me after you arrive.
```

# 3. Correlative Conjunctions

These work in **pairs**.

---

## Common Pairs

| First | Second |
|--------|---------|
| Either | Or |
| Neither | Nor |
| Both | And |
| Not Only | But Also |
| Whether | Or |
| Such | That |
| So | That |

---

## Examples

### Either...Or

```
Either Rahul or Amit will lead the team.
```

---

### Neither...Nor

```
Neither Ram nor Shyam was present.
```

---

### Both...And

```
She is both intelligent and hardworking.
```

---

### Not Only...But Also

```
He is not only honest but also kind.
```

---

### Whether...Or

```
I don't know whether he will come or not.
```

---

# Coordinating vs Subordinating

| Coordinating | Subordinating |
|---------------|---------------|
| Joins equals | Joins unequal clauses |
| And | Because |
| But | Although |
| Or | If |
| So | Since |

---

# Commonly Confused Conjunctions

---

## Because vs Since

### Because

Shows **reason**.

```
He stayed home because he was sick.
```

---

### Since

Can mean **reason** or **time**.

```
Since it was raining, we stayed inside.

(Time or reason depending on context.)
```

---

## Though vs Although

Both express contrast.

```
Although he is rich, he is humble.

Though he is rich, he is humble.
```

Both are generally interchangeable.

---

## Unless vs If...Not

These have similar meanings.

```
Unless you study,

=

If you do not study
```

Example

```
Unless you leave now, you'll miss the train.

=

If you do not leave now, you'll miss the train.
```

---

# Parallel Structure

Words joined by conjunctions should have the same grammatical form.

---

## Correct

```
She likes reading, writing, and painting.
```

---

## Incorrect

```
She likes reading, to write, and painting.
```

---

## Correct

```
He is honest and hardworking.
```

---

## Incorrect

```
He is honest and works hard.
```

(Unless the sentence is intentionally mixing structures.)

---

# Subject-Verb Agreement with Correlative Conjunctions

With **Either...Or** and **Neither...Nor**,

the verb agrees with the **nearest subject**.

---

## Examples

```
Either Rahul or his friends are coming.
```

Nearest subject

```
Friends

↓

Are
```

---

```
Either the students or the teacher is present.
```

Nearest subject

```
Teacher

↓

Is
```

# Common GATE & Placement Errors

### Incorrect

```
Although he was tired but he continued working.
```

Correct

```
Although he was tired, he continued working.
```

or

```
He was tired, but he continued working.
```

---

### Incorrect

```
Neither Rahul or Amit came.
```

Correct

```
Neither Rahul nor Amit came.
```

---

### Incorrect

```
Both Rahul as well as Amit came.
```

Correct

```
Both Rahul and Amit came.
```

---

### Incorrect

```
He is not only smart but clever also.
```

Correct

```
He is not only smart but also clever.
```

# Common Mistakes

❌ Using

```
Although

+

But
```

together.

---

❌ Using

```
Because

+

So
```

together.

Incorrect

```
Because it rained, so we stayed home.
```

Correct

```
Because it rained, we stayed home.
```

or

```
It rained, so we stayed home.
```

---

❌ Mixing correlative conjunctions.

Correct pairs

- Either...Or
- Neither...Nor
- Both...And
- Not Only...But Also

---

❌ Breaking parallel structure.
