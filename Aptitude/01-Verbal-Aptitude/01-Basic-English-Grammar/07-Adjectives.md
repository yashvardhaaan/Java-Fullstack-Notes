# Why Learn Adjectives?

Imagine these two sentences.

```
I bought a car.
```

```
I bought a red sports car.
```

Which sentence gives more information?

The second one.

Adjectives make sentences

- More descriptive
- More specific
- More interesting

They are frequently tested in

- Error Spotting
- Fill in the Blanks
- Sentence Correction
- Reading Comprehension

---

# What is an Adjective?

An **Adjective** is a word that **describes or modifies a noun or pronoun**.

It answers questions like

- Which?
- What kind?
- How many?
- Whose?

---

# Examples

```
Beautiful girl

Red car

Five books

Indian player

Honest man
```

---

# Example Sentences

```
She has a beautiful dress.

He is an intelligent student.

The old building needs repair.
```

# 1. Adjective of Quality

Describes the quality or nature of a noun.

---

## Examples

```
Beautiful

Honest

Tall

Brave

Smart
```

---

## Example Sentences

```
She is an honest person.

The beautiful garden attracts tourists.
```

---

# 2. Adjective of Quantity

Shows **how much** of something.

Used mainly with uncountable nouns.

---

## Examples

```
Some

Little

Much

Enough

No
```

---

## Example Sentences

```
There is little water.

I have enough money.

She has much patience.
```

---

# 3. Adjective of Number

Shows **how many**.

Used with countable nouns.

---

## Examples

```
One

Two

Many

Few

Several

First
```

---

## Example Sentences

```
Three students were absent.

Many books are available.

The first prize is yours.
```

---

# Quantity vs Number

| Quantity | Number |
|----------|---------|
| Much water | Many books |
| Little milk | Few students |
| Enough sugar | Several cars |

---

# 4. Demonstrative Adjectives

Point to a specific noun.

---

## Examples

```
This

That

These

Those
```

---

## Example Sentences

```
This book is interesting.

Those flowers are beautiful.
```

---

# Demonstrative Adjective vs Demonstrative Pronoun

### Adjective

```
This book is mine.
```

(Book follows "This")

---

### Pronoun

```
This is mine.
```

(No noun follows.)

---

# 5. Possessive Adjectives

Show ownership.

Always followed by a noun.

---

## Examples

```
My

Your

His

Her

Its

Our

Their
```

---

## Example Sentences

```
My phone is new.

Their house is large.
```

---

# Possessive Adjective vs Possessive Pronoun

| Possessive Adjective | Possessive Pronoun |
|----------------------|--------------------|
| My book | Mine |
| Your pen | Yours |
| Our home | Ours |
| Their car | Theirs |

---

# 6. Interrogative Adjectives

Used with nouns to ask questions.

---

## Examples

```
Which

What

Whose
```

---

## Example Sentences

```
Which book do you want?

Whose bag is this?

What subject do you like?
```

---

# 7. Proper Adjectives

Derived from proper nouns.

Always begin with a capital letter.

---

## Examples

```
Indian

American

French

Japanese

Shakespearean
```

---

## Example Sentences

```
Indian food is delicious.

She studies French literature.
```

---

# 8. Distributive Adjectives

Refer to members of a group individually.

---

## Examples

```
Each

Every

Either

Neither
```

---

## Example Sentences

```
Each student received a certificate.

Every child deserves education.
```

# Degrees of Comparison

Adjectives have three degrees.

```
Positive

↓

Comparative

↓

Superlative
```

---

# Positive Degree

Used without comparison.

Examples

```
Tall

Fast

Beautiful
```

---

# Comparative Degree

Used to compare **two** things.

Usually ends with

```
-er
```

or uses

```
More
```

---

## Examples

```
Taller

Faster

More beautiful
```

---

## Example

```
Rahul is taller than Amit.
```

---

# Superlative Degree

Used to compare **three or more**.

Usually ends with

```
-est
```

or uses

```
Most
```

---

## Examples

```
Tallest

Fastest

Most beautiful
```

---

## Example

```
Mount Everest is the highest mountain.
```

---

# Degrees Table

| Positive | Comparative | Superlative |
|------------|--------------|--------------|
| Tall | Taller | Tallest |
| Small | Smaller | Smallest |
| Fast | Faster | Fastest |
| Beautiful | More Beautiful | Most Beautiful |
| Intelligent | More Intelligent | Most Intelligent |

---

# Irregular Comparisons

| Positive | Comparative | Superlative |
|-----------|--------------|--------------|
| Good | Better | Best |
| Bad | Worse | Worst |
| Little | Less | Least |
| Many | More | Most |
| Far | Farther/Further | Farthest/Furthest |

---

# Order of Adjectives

When multiple adjectives describe one noun, they usually follow this order.

```
Opinion

↓

Size

↓

Age

↓

Shape

↓

Color

↓

Origin

↓

Material

↓

Purpose

↓

Noun
```

---

## Example

```
A beautiful small old round red Indian wooden dining table.
```

Although uncommon in daily speech, this illustrates the typical adjective order.

# Common GATE & Placement Errors

### Incorrect

```
He is more taller than me.
```

Correct

```
He is taller than me.
```

---

### Incorrect

```
This is the most fastest train.
```

Correct

```
This is the fastest train.
```

---

### Incorrect

```
She is elder than her brother.
```

Correct

```
She is older than her brother.
```

("Elder" is mainly used within family relationships and is not followed by **than**.)

---

### Incorrect

```
He is an enough smart boy.
```

Correct

```
He is a smart enough boy.
```

or

```
He is smart enough.
```

(depending on meaning)

# Common Mistakes

❌ Using **more** with adjectives already ending in **-er**.

Incorrect

```
More stronger
```

Correct

```
Stronger
```

---

❌ Using **most** with adjectives already ending in **-est**.

Incorrect

```
Most tallest
```

Correct

```
Tallest
```

---

❌ Confusing **many** and **much**.

```
Many

↓

Countable
```

```
Much

↓

Uncountable
```

---

❌ Incorrect adjective order.

# Interview Corner

### Q1. What is an adjective?

An adjective is a word that **describes or modifies a noun or pronoun**.

---

### Q2. What are the three degrees of comparison?

- Positive
- Comparative
- Superlative

Example:

```
Fast

↓

Faster

↓

Fastest
```

---

### Q3. What is the difference between an adjective of quantity and an adjective of number?

- **Quantity** tells **how much** (used with uncountable nouns).
- **Number** tells **how many** (used with countable nouns).

Examples:

```
Much water

Many books
```
