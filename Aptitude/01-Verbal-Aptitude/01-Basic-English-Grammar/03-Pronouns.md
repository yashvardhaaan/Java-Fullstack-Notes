# Why Learn Pronouns?

Imagine writing

```
Rahul is a good student.

Rahul studies every day.

Rahul helps Rahul's friends.
```

This sounds repetitive.

Instead, we use pronouns.

```
Rahul is a good student.

He studies every day.

He helps his friends.
```

Pronouns make sentences

- Short
- Clear
- Natural

---

# What is a Pronoun?

A **Pronoun** is a word used **instead of a noun**.

It avoids unnecessary repetition.

# 1. Personal Pronouns

Used to refer to people or things.

---

## Subject Pronouns

| Person | Pronoun |
|---------|----------|
| First | I, We |
| Second | You |
| Third | He, She, It, They |

---

## Object Pronouns

| Subject | Object |
|----------|---------|
| I | Me |
| We | Us |
| You | You |
| He | Him |
| She | Her |
| It | It |
| They | Them |

---

## Examples

```
She is my friend.

I helped her.
```

---

# 2. Possessive Pronouns

Show ownership.

---

## Examples

```
Mine

Yours

His

Hers

Ours

Theirs
```

---

## Example Sentences

```
This book is mine.

That car is yours.
```

---

# Possessive Pronoun vs Possessive Adjective

| Possessive Adjective | Possessive Pronoun |
|----------------------|--------------------|
| My | Mine |
| Your | Yours |
| His | His |
| Her | Hers |
| Our | Ours |
| Their | Theirs |

---

Example

```
This is my pen.

This pen is mine.
```

---

# 3. Reflexive Pronouns

Used when the subject and object are the same.

Ends with

```
-self

-selves
```

---

## Examples

```
Myself

Yourself

Himself

Herself

Itself

Ourselves

Themselves
```

---

## Example Sentences

```
She hurt herself.

I completed the work myself.
```

---

---

## Examples

```

---

# 5. Interrogative Pronouns

Used to ask questions.

---

## Examples

```

Whom

---

## Example Sentences

```

```

---

# 6. Relative Pronouns

Join two clauses.

---

## Examples

```
Who

Whom

Whose

Which

That
```

---

## Example

```

```

---

# 7. Indefinite Pronouns

Refer to non-specific persons or things.

---

## Examples

```
Someone

Anyone

Everyone

Nobody

Everything

Nothing
```

---

## Example

```
Someone is knocking.

Everybody enjoyed the movie.
```

---

# 8. Distributive Pronouns

Refer to members of a group individually.

---

## Examples

```
Each

Either

Neither
```

---

## Example

```
Each of the students received a prize.

Neither of the answers is correct.
```

---

# 9. Reciprocal Pronouns

Show mutual action.

---

## Examples

```
Each other

One another
```

---

## Example

```
The two friends helped each other.

The team members respected one another.
```

# Pronoun Case

There are three grammatical cases.

| Case | Example |
|------|----------|
| Subjective | I, He, She |
| Objective | Me, Him, Her |
| Possessive | Mine, Yours, His |

# Pronoun Agreement

A pronoun must agree with its noun in

- Number
- Gender
- Person

---

## Correct

```
Rahul forgot his bag.
```

---

## Incorrect

```
Rahul forgot her bag.
```

---

# Gender Pronouns

| Gender | Pronoun |
|----------|----------|
| Male | He, Him, His |
| Female | She, Her, Hers |
| Neutral | It, Its |
| Plural | They, Them, Their |

# Common GATE & Placement Errors

### Incorrect

```
Me and Rahul went to school.
```

Correct

```
Rahul and I went to school.
```

---

### Incorrect

```
Each student should submit their assignment.
```

Traditional grammar prefers

```
Each student should submit his or her assignment.
```

In modern English, singular **they** is also widely accepted:

```
Each student should submit their assignment.
```

---

### Incorrect

```
This book is her.
```

Correct

```
This book is hers.
```

---

### Incorrect

```
The boys enjoyed himself.
```

Correct

```
The boys enjoyed themselves.
```

# Who vs Whom

## Who

Used as the **subject**.

```
Who called you?
```

---

## Whom

Used as the **object**.

```
Whom did you meet?
```

Easy Trick

Replace with

```
He

↓

Who
```

Replace with

```
Him

↓

Whom
```

---

# Its vs It's

```
Its

↓

Possession
```

Example

```
The dog wagged its tail.
```

---

```
It's

↓

It is
```

Example

```
It's raining.
```

---

# One vs Ones

```
One

↓

Singular
```

```
Ones

↓

Plural
```

Example

```
This one is expensive.

These ones are cheaper.
```

# Interview Corner

### Q1. What is a pronoun?

A pronoun is a word that replaces a noun to avoid repetition.

---

### Q2. What is the difference between "my" and "mine"?

- **My** is a possessive adjective and must be followed by a noun.
- **Mine** is a possessive pronoun and stands alone.

Example:

```
My book

The book is mine.
```

---

### Q3. What is a reflexive pronoun?

A reflexive pronoun refers back to the subject of the sentence.

Example:

```
She introduced herself.
```
