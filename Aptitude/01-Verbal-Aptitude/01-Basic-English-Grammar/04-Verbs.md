# Why Learn Verbs?

A sentence without a verb is usually incomplete.

Example

```
Rahul a student.
```

❌ Incorrect

Correct

```
Rahul is a student.
```

The verb is called the **heart of a sentence** because it tells us

- What someone does
- What happens
- What someone is

---

# What is a Verb?

A **Verb** is a word that shows

- Action
- State
- Occurrence

# 5. Transitive Verbs

A **Transitive Verb** requires an object.

Ask

```
Verb

↓

What?

Whom?
```

If an answer exists,

it is transitive.

---

## Example

```
Rahul bought a laptop.
```

Verb

```
Bought
```

Object

```
Laptop
```

---

# More Examples

```
Read a book.

Eat food.

Write a letter.
```

---

# 6. Intransitive Verbs

An **Intransitive Verb** does **not** require an object.

---

## Example

```
The baby cried.
```

No object.

---

More examples

```
Sleep

Arrive

Laugh

Cry

Go
```

---

# Difference

| Transitive | Intransitive |
|------------|--------------|
| Needs Object | No Object |
| Read a book | Sleep |
| Buy a car | Arrive |

---

# 7. Finite Verbs

A finite verb changes according to

- Person
- Number
- Tense

---

## Examples

```
He plays.

They play.

She played.
```

---

# 8. Non-Finite Verbs

Do not change according to tense or subject.

Types

```
Infinitive

Gerund

Participle
```

---

## Infinitive

Usually begins with

```
To
```

Examples

```
To eat

To study

To write
```

---

Example

```
I want to learn Java.
```

---

## Gerund

Verb + ing

Acts like a noun.

Examples

```
Swimming

Reading

Coding
```

---

Example

```
Reading improves knowledge.
```

---

## Participle

Acts like an adjective.

Examples

```
Broken

Running

Written
```

---

Example

```
The broken chair needs repair.
```

# Verb Agreement

The verb must agree with the subject.

Correct

```
He plays.
```

Incorrect

```
He play.
```

---

Correct

```
They play.
```

Incorrect

```
They plays.
```

```

```

# Interview Corner

### Q1. What is a verb?

A verb is a word that expresses an **action, state, or occurrence**.

---

### Q2. What is the difference between a transitive and an intransitive verb?

- **Transitive Verb:** Requires an object.
- **Intransitive Verb:** Does not require an object.

Example:

```
She wrote a letter.

(Transitive)
```

```
She slept.

(Intransitive)
```

---

### Q3. What are modal verbs?

Modal verbs are helping verbs that express **ability, permission, possibility, obligation, or advice**.

Examples:

```
Can

Should

Must

May
```
