# 1. Subject-Verb Agreement Errors

The subject and verb must agree in **number**.

### Incorrect

```
He go to school.
```

### Correct

```
He goes to school.
```

---

### Incorrect

```
The students studies daily.
```

### Correct

```
The students study daily.
```

---

### Incorrect

```
Everyone are happy.
```

### Correct

```
Everyone is happy.
```

---

# 2. Tense Errors

Maintain consistent tense unless the time changes.

### Incorrect

```
She went to school and meets her friend.
```

### Correct

```
She went to school and met her friend.
```

---

### Incorrect

```
I am living here since 2020.
```

### Correct

```
I have been living here since 2020.
```

---

# 3. Article Errors

### Incorrect

```
He is engineer.
```

### Correct

```
He is an engineer.
```

---

### Incorrect

```
Sun rises in east.
```

### Correct

```

```

# 4. Preposition Errors

### Incorrect

```
She is married with him.
```

### Correct

```
She is married to him.
```

---

### Incorrect

```
He is good in Mathematics.
```

### Correct

```
He is good at Mathematics.
```

---

### Incorrect

```
Discuss about the issue.
```

### Correct

```
Discuss the issue.
```

# 5. Pronoun Errors

Pronouns must agree with their nouns.

### Incorrect

```
Every student should bring their notebook.
```

### Formal Grammar

```
Every student should bring his or her notebook.
```

### Modern Usage

```
Every student should bring their notebook.
```

(Both may be accepted depending on style guides.)

---

### Incorrect

```
Me and Rahul went home.
```

### Correct

```
Rahul and I went home.
```

# 6. Adjective vs Adverb Errors

### Incorrect

```
She sings beautiful.
```

### Correct

She sings beautifully.

### Incorrect

```

```

# 7. Double Negative

Avoid using two negatives unless intentionally required.

### Incorrect

```
I don't know nothing.
```

### Correct

```
I don't know anything.
```

---

### Incorrect

```
She never said nothing.
```

### Correct

```
She never said anything.
```

---

# 8. Conjunction Errors

### Incorrect

```
Although he was tired but he worked.
```

### Correct

```
Although he was tired, he worked.
```

OR

```
He was tired, but he worked.
```

---

### Incorrect

```
Because it rained, so we stayed home.
```

### Correct

```
Because it rained, we stayed home.
```

OR

```
It rained, so we stayed home.
```

---

# 9. Parallelism Errors

Items in a list should have the same grammatical form.

### Incorrect

```
She likes reading, to write, and dancing.
```

### Correct

```
She likes reading, writing, and dancing.
```

---

### Incorrect

```
He is honest and works hard.
```

Better

```
He is honest and hardworking.
```

---

# 10. Comparison Errors

Compare similar things.

### Incorrect

```
My laptop is better than Rahul.
```

### Correct

```
My laptop is better than Rahul's laptop.
```

---

### Incorrect

```
She is smarter than anyone in the class.
```

### Correct

```
She is smarter than anyone else in the class.
```

# 11. Confusing Word Pairs

---

## Accept vs Except

| Word | Meaning |
|------|----------|
| Accept | Receive |
| Except | Excluding |

Example

```
I accept your offer.

Everyone came except Rahul.
```

---

## Affect vs Effect

| Word | Meaning |
|------|----------|
| Affect | Verb (Influence) |
| Effect | Noun (Result) |

Example

```
The weather affected our plans.

The new policy had a positive effect.
```

---

## Then vs Than

| Word | Meaning |
|------|----------|
| Then | Time |
| Than | Comparison |

Example

```
Finish your work, then relax.

She is taller than me.
```

---

## Your vs You're

| Word | Meaning |
|------|----------|
| Your | Possession |
| You're | You are |

Example

```
Your book is here.

You're doing great.
```

---

## Its vs It's

| Word | Meaning |
|------|----------|
| Its | Possessive |
| It's | It is |

Example

```
The dog wagged its tail.

It's raining today.
```

---

## Lose vs Loose

| Word | Meaning |
|------|----------|
| Lose | Misplace / Fail to win |
| Loose | Not tight |

Example

```
Don't lose your keys.

This shirt is loose.
```

---

## Principle vs Principal

| Word | Meaning |
|------|----------|
| Principle | Rule or belief |
| Principal | Head of a school / Main |

Example

```
Honesty is an important principle.

The principal addressed the students.
```

---

# 13. Sentence Fragments

A complete sentence needs:

- Subject
- Verb
- Complete thought

---

### Incorrect

```
Because he was late.
```

(Not a complete sentence.)

---

### Correct

```
Because he was late, he missed the train.
```

---

# 14. Run-on Sentences

Do not join two independent sentences without proper punctuation or conjunctions.

### Incorrect

```
I was tired I went to bed.
```

### Correct

```
I was tired, so I went to bed.
```

# Top 25 Grammar Rules for Revision

✅ Subject and verb must agree.

✅ Use **a/an** before singular countable nouns.

✅ Use **the** for unique objects.

✅ Use correct prepositions.

✅ Use the correct tense.

✅ Avoid double negatives.

✅ Maintain parallel structure.

✅ Use adverbs to modify verbs.

✅ Use adjectives to modify nouns.

✅ Avoid redundant words.

✅ Don't mix **because** and **so**.

✅ Don't mix **although** and **but**.

✅ Use **Either...Or** correctly.

✅ Use **Neither...Nor** correctly.

✅ Compare similar things.

✅ Use **than** for comparison.

✅ Use **then** for sequence.

✅ Use **its** and **it's** correctly.

✅ Use **your** and **you're** correctly.

✅ Use **affect** and **effect** correctly.

✅ Use **lose** and **loose** correctly.

✅ Avoid sentence fragments.

✅ Avoid run-on sentences.

✅ Read the sentence twice before answering.

✅ Eliminate obviously wrong options first in MCQs.
