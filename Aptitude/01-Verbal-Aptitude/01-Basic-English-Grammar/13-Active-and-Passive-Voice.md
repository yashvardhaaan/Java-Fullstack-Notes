# What is Voice?

**Voice** shows whether the **Subject** performs the action or receives the action.

There are **two voices**.

```
Voice
│
├── Active Voice
└── Passive Voice
```

---

# Active Voice

In Active Voice,

**Subject performs the action.**

### Structure

```
Subject

↓

Verb

↓

Object
```

---

### Examples

```
Rahul writes a letter.

The teacher praised the student.

She completed the project.
```

---

# Passive Voice

In Passive Voice,

**Subject receives the action.**

### Structure

```
Object

↓

Helping Verb

↓

V3

↓

by + Subject
```

---

### Examples

```
A letter is written by Rahul.

The student was praised by the teacher.

The project was completed by her.
```

---

# Active vs Passive

| Active Voice | Passive Voice |
|--------------|---------------|
| Subject performs action | Subject receives action |
| Rahul wrote a letter. | A letter was written by Rahul. |
| She cleaned the room. | The room was cleaned by her. |

---

# Basic Formula

```
Active

Subject

+

Verb

+

Object
```

↓

```
Passive

Object

+

Helping Verb

+

V3

+

by + Subject
```

---

# Step-by-Step Conversion

Example

```
Rahul writes a letter.
```

### Step 1

Object becomes Subject.

```
A letter
```

---

### Step 2

Choose correct Helping Verb.

```
Is
```

---

### Step 3

Use V3.

```
Written
```

---

### Step 4

Add

```
By Rahul
```

---

Final Answer

```
A letter is written by Rahul.
```

# Sentences Without Passive Voice

Passive Voice is generally **not** possible with

### Intransitive Verbs

```
Sleep

Arrive

Laugh

Cry

Go
```

Example

```
He slept.
```

(No object, so no passive form.)

---

# When to Use Passive Voice?

Use Passive Voice when

- The doer is unknown.
- The doer is unimportant.
- The action is more important than the doer.
- Writing scientific or formal reports.

---

## Examples

```
The bridge was built in 2024.
```

(The builder is not important.)

---

```
The results were announced yesterday.
```

# Interview Corner

### Q1. What is the difference between Active and Passive Voice?

- **Active Voice:** The subject performs the action.
- **Passive Voice:** The subject receives the action.

---

### Q2. Can every sentence be converted into Passive Voice?

No. Only sentences with **transitive verbs** (verbs that take an object) can generally be converted into Passive Voice.

---

### Q3. What is the basic formula for Passive Voice?

```
Object + Be Verb + V3 + by + Subject
```
