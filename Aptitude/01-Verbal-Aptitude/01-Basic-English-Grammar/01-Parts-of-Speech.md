# Why Learn Parts of Speech?

Every English sentence is made up of different kinds of words.

Each word has a specific job.

These jobs are called **Parts of Speech**.

Without understanding Parts of Speech, it becomes difficult to learn:

- Tenses
- Subject-Verb Agreement
- Active & Passive Voice
- Direct & Indirect Speech
- Sentence Correction
- Reading Comprehension

---

# What are Parts of Speech?

A **Part of Speech** tells us the **function** of a word in a sentence.

Example

```
Rahul plays cricket every Sunday.
```

| Word | Part of Speech |
|------|----------------|
| Rahul | Noun |
| plays | Verb |
| cricket | Noun |
| every | Adjective |
| Sunday | Noun |

# 1. Noun

## Definition

A **Noun** is the name of a

- Person
- Place
- Thing
- Animal
- Idea

---

## Examples

```
Rahul

India

Computer

Dog

Honesty
```

---

## Example Sentences

```
Rahul is studying.

Delhi is beautiful.

Honesty is the best policy.
```

---

# Identification Trick

Ask yourself

```
Who?

What?

Which Place?

Which Thing?
```

The answer is usually a noun.

---

# 2. Pronoun

## Definition

A **Pronoun** replaces a noun.

---

## Examples

```
I

You

He

She

It

We

They
```

---

## Example

Instead of

```
Rahul is a student.

Rahul studies daily.
```

Write

```
Rahul is a student.

He studies daily.
```

---

# Identification Trick

If a word replaces a noun,

it is usually a pronoun.

---

# 3. Verb

## Definition

A **Verb** shows

- Action
- State
- Occurrence

---

## Examples

```
Run

Eat

Study

Sleep

Write
```

---

## Example Sentences

```
She sings.

They play football.

The baby sleeps.
```

---

# Identification Trick

Ask

```
What is happening?

What action is being performed?
```

---

# 4. Adjective

## Definition

An **Adjective** describes a noun or pronoun.

It tells

- Which?
- What kind?
- How many?

---

## Examples

```
Beautiful

Tall

Red

Three

Intelligent
```

---

## Example Sentences

```
She has a beautiful dress.

He is a tall boy.

I bought three books.
```

---

# Identification Trick

If a word gives extra information about a noun,

it is an adjective.

---

# 5. Adverb

## Definition

An **Adverb** modifies

- Verb
- Adjective
- Another Adverb

It answers

- How?
- When?
- Where?
- How often?

---

## Examples

```
Quickly

Slowly

Yesterday

Very

Always
```

---

## Example Sentences

```
He runs quickly.

She is very intelligent.

They arrived yesterday.
```

---

# Identification Trick

Many adverbs end with

```
-ly
```

Examples

```
Quickly

Slowly

Carefully
```

But not all.

Example

```
Fast

Well

Often
```

---

# 6. Preposition

## Definition

A **Preposition** shows the relationship between words.

Usually indicates

- Place
- Time
- Direction

---

## Examples

```
In

On

At

Under

Behind

Between

Into
```

---

## Example Sentences

```
The book is on the table.

She arrived at 9 AM.

The cat is under the chair.
```

---

# Identification Trick

Think

```
Where?

When?

Position?
```

---

# 7. Conjunction

## Definition

A **Conjunction** joins

- Words
- Phrases
- Clauses

---

## Examples

```
And

But

Or

Because

Although

So
```

---

## Example Sentences

```
Rahul and Amit are friends.

She worked hard because she wanted to succeed.

I wanted to go, but it was raining.
```

---

# Identification Trick

If the word joins two ideas,

it is a conjunction.

---

# 8. Interjection

## Definition

An **Interjection** expresses sudden emotions.

---

## Examples

```
Wow!

Oh!

Hurrah!

Oops!

Alas!
```

---

## Example Sentences

```
Wow! That is amazing.

Oops! I dropped my phone.

Hurrah! We won.
```

---

# Identification Trick

Usually followed by

```
!
```

and expresses emotion.

| If the word... | It is probably... |
|---------------|-------------------|
| Names something | Noun |

| Shows action | Verb |

# Common Mistakes

### ❌ Mistake 1

Thinking every word ending in **-ly** is an adverb.

Example

```
Friendly
```

is an adjective.

---

### ❌ Mistake 2

Confusing adjectives and adverbs.

```
He is a quick runner.

(Adjective)
```

```
He runs quickly.

(Adverb)
```

---

### ❌ Mistake 3

Using pronouns without a clear noun.

Incorrect

```
Rahul met Amit.

He was happy.
```

Who was happy?

# Practice Questions

## Identify the Part of Speech

### Q1

```
The dog barked loudly.
```

**Answer**

| Word | Part of Speech |
|------|----------------|
| The | Article |
| dog | Noun |
| barked | Verb |
| loudly | Adverb |

---

### Q2

```
She bought a beautiful dress.
```

**Answer**

| Word | Part of Speech |
|------|----------------|
| She | Pronoun |
| bought | Verb |
| a | Article |
| beautiful | Adjective |
| dress | Noun |

---

### Q3

```
Wow! You solved it quickly.
```

**Answer**

| Word | Part of Speech |
|------|----------------|
| Wow | Interjection |
| You | Pronoun |
| solved | Verb |
| it | Pronoun |
| quickly | Adverb |

# Interview Corner

### Q1. What are the Parts of Speech?

Parts of Speech are categories of words based on their function in a sentence.

---

### Q2. Which Part of Speech is the most important?

The **Verb** is often considered the heart of a sentence because every complete sentence requires a verb.

---

### Q3. How many Parts of Speech are there?

There are **eight traditional Parts of Speech**:

- Noun
- Pronoun
- Verb
- Adjective
- Adverb
- Preposition
- Conjunction
- Interjection
