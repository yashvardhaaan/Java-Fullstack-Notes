# Why Learn Subject-Verb Agreement?

One of the most common grammatical errors is using the wrong verb with the subject.

Incorrect

```
He go to school.
```

Correct

```
He goes to school.
```

In every sentence, the **subject** and the **verb** must agree in **number** and **person**.

This topic is one of the most frequently asked in

- Error Spotting
- Sentence Correction
- Fill in the Blanks
- Interviews

---

# What is Subject-Verb Agreement?

**Subject-Verb Agreement** means the verb must match the subject.

- Singular Subject → Singular Verb
- Plural Subject → Plural Verb

---

# Basic Rule

| Subject | Verb |
|----------|------|
| He | Goes |
| She | Writes |
| It | Runs |
| Rahul | Plays |
| They | Go |
| We | Write |
| Students | Study |

---

# Rule 1: Singular Subject → Singular Verb

Examples

```
Rahul plays cricket.

The dog barks.

She sings well.
```

---

# Rule 2: Plural Subject → Plural Verb

Examples

```
The students study daily.

Dogs bark loudly.

They work hard.
```

---

# Rule 3: Two Subjects Joined by "And"

Usually take a **plural verb**.

Examples

```
Rahul and Amit are friends.

Tea and coffee are available.
```

---

## Exception

When two nouns refer to the **same person or thing**, use a **singular verb**.

Example

```
The principal and secretary is arriving.
```

(One person holding both positions.)

---

# Rule 4: Subjects Joined by "Or", "Nor", "Either...Or", "Neither...Nor"

The verb agrees with the **nearest subject**.

Examples

```
Either Rahul or his friends are coming.
```

Nearest subject

```
Friends

↓

Are
```

---

```
Either the students or the teacher is present.
```

Nearest subject

```
Teacher

↓

Is
```

---

# Rule 5: Collective Nouns

Collective nouns usually take a **singular verb** when the group acts as one unit.

Examples

```
The team is winning.

The committee has submitted its report.
```

When emphasizing **individual members**, a plural verb may be used (more common in British English).

Example

```
The team are arguing among themselves.
```

---

# Rule 6: Indefinite Pronouns

## Singular

Always take singular verbs.

```
Everyone

Someone

Anyone

Nobody

Each

Either

Neither

Everybody
```

Examples

```
Everyone is happy.

Each student has a notebook.

Nobody knows the answer.
```

---

## Plural

```
Few

Many

Several

Both
```

Examples

```
Many were absent.

Few know the truth.
```

---

## Can Be Singular or Plural

Depends on the noun that follows.

```
Some

Any

All

Most

None
```

Examples

```
Some water is left.

Some books are missing.
```

---

# Rule 7: "Each" and "Every"

Always followed by a **singular verb**.

Examples

```
Each boy has a pencil.

Every student is ready.
```

---

# Rule 8: Amounts of Money, Time, Distance

When treated as a **single unit**, use a singular verb.

Examples

```
Ten dollars is enough.

Five years is a long time.

Ten kilometers is too far to walk.
```

---

# Rule 9: Titles of Books, Movies, Newspapers

Even if plural in form, they take a singular verb.

Examples

```
"Gulliver's Travels" is a famous novel.

"The Chronicles of Narnia" is popular.
```

---

# Rule 10: "There Is" / "There Are"

The verb agrees with the noun **after** it.

Examples

```
There is a book on the table.

There are many books on the shelf.
```

---

# Rule 11: "One of"

Use a singular verb.

Examples

```
One of the students is absent.

One of my friends has a bike.
```

---

# Rule 12: "The Number of" vs "A Number of"

### The Number of

Singular verb

```
The number of students is increasing.
```

---

### A Number of

Plural verb

```
A number of students are absent.
```

---

# Rule 13: Fractions and Percentages

The verb depends on the noun after **of**.

Examples

```
Half of the cake is gone.

Half of the students are present.

Sixty percent of the work is complete.

Sixty percent of the employees are satisfied.
```

---

# Rule 14: Subjects with "Along With", "As Well As", "Together With"

The verb agrees with the **first subject**.

Examples

```
Rahul, along with his friends, is going.

The teacher, as well as the students, was present.
```

---

# Rule 15: Nouns That Look Plural but Are Singular

These take singular verbs.

Examples

```
Mathematics is interesting.

Physics is difficult.

Economics is useful.
```

---

# Rule 16: Plural-Only Nouns

These always take plural verbs.

Examples

```
Scissors are on the table.

Trousers are expensive.

Glasses are clean.
```

---

# Commonly Confused Cases

---

## News

Although it ends in **s**, it is singular.

```
The news is good.
```

---

## Politics

Usually singular when referring to the subject.

```
Politics is an interesting subject.
```

---

## Data

Modern English often treats **data** as plural in formal writing.

```
The data are accurate.
```

In everyday English, **The data is...** is also common.

Correct

---

Correct


- Either...Or
- Neither...Nor

---

# Interview Corner

### Q1. What is Subject-Verb Agreement?

Subject-Verb Agreement means that the verb must agree with the subject in **number** and **person**.

---

### Q2. Which verb is used with **Everyone**?

**Everyone** is singular, so it always takes a **singular verb**.

Example

```
Everyone is ready.
```

---

### Q3. What is the difference between **The Number of** and **A Number of**?

- **The Number of** → Singular Verb
- **A Number of** → Plural Verb

Examples

```
The number of students is increasing.

A number of students are absent.
```
