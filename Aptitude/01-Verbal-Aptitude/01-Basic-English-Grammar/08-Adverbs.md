# Why Learn Adverbs?

Compare these two sentences.

```
She sings.
```

```
She sings beautifully.
```

The second sentence gives more information about **how** she sings.

That extra information comes from an **Adverb**.

Adverbs make sentences more meaningful and are commonly tested in

- Error Spotting
- Fill in the Blanks
- Sentence Correction
- Reading Comprehension

---

# What is an Adverb?

An **Adverb** is a word that modifies or describes

- A Verb
- An Adjective
- Another Adverb
- Sometimes an entire sentence

It answers questions like

- How?
- When?
- Where?
- How often?
- To what extent?

---

# Examples

```
He runs quickly.

She is very intelligent.

They arrived yesterday.

The child plays outside.
```

# 1. Adverb of Manner

Describes **how** an action is performed.

---

## Examples

```

Slowly

Carefully

Beautifully

Bravely
```

---

## Example Sentences

```
She danced beautifully.

He spoke politely.
```

---

# 2. Adverb of Place

Describes **where** an action happens.

---

## Examples

```
Here

There

Outside

Inside

Nearby

Everywhere
```

---

## Example Sentences

```

```

# 3. Adverb of Time

Describes **when** an action happens.

```
Tomorrow
```

# 5. Adverb of Degree

Shows the intensity or extent of something.

---

## Examples

```

Quite

Almost
```

---

## Example Sentences


# 6. Adverb of Reason

Explains **why** something happens.

---

## Examples

```
Therefore

Thus

```

---

## Example Sentences


---

---

## Example Sentences

# Position of Adverbs

The position depends on the type of adverb.

---

## Adverb of Manner

Usually comes **after the verb**.

Example

```
She sings beautifully.
```

---

## Adverb of Frequency

Usually comes **before the main verb**.

Example

```
She always studies.
```

Exception

With the verb **to be**, it comes after the verb.

```
She is always cheerful.
```

---

## Adverb of Time

Usually comes at the **beginning or end** of the sentence.

Examples

```
Yesterday, we visited the museum.

We visited the museum yesterday.
```

# Adjective vs Adverb

| Adjective | Adverb |
|-----------|---------|
| Quick | Quickly |
| Slow | Slowly |
| Careful | Carefully |
| Happy | Happily |
| Loud | Loudly |

---

## Examples

```
He is a quick learner.

(Adjective)
```

```
He learns quickly.

(Adverb)
```

---

# Common Exceptions

Some words have the **same form** as both adjectives and adverbs.

Examples

```
Fast

Hard

Late

Early
```

---

## Examples

```

(Adjective)
```

```
He runs fast.

(Adverb)
```

# Hard vs Hardly

These words have different meanings.

---

## Hard

Means

```
With great effort
```

Example

```
She works hard.
```

---

## Hardly

Means

```
Almost not
```

Example

```
She hardly works.
```

---

# Late vs Lately

## Late

Means

```
Not on time
```

Example

```
He arrived late.
```

---

## Lately

Means

```
Recently
```

Example

```
I haven't seen him lately.
```

---

# Well vs Good

## Good

Adjective

```
She is a good singer.
```

---

## Well

Adverb

```
She sings well.
```

# Interview Corner

### Q1. What is an adverb?

An adverb is a word that modifies a **verb, adjective, another adverb, or an entire sentence**.

---

### Q2. What is the difference between an adjective and an adverb?

- **Adjective** describes a noun or pronoun.
- **Adverb** describes a verb, adjective, or another adverb.

Example

```
She is a careful driver.

(Adjective)
```

```
She drives carefully.

(Adverb)
```

---

### Q3. Why is "She sings well" correct instead of "She sings good"?

Because **"sings"** is a verb, so it should be modified by an **adverb** (**well**), not an adjective (**good**).
