# What is a Synonym?

A **Synonym** is a word that has the **same or nearly the same meaning** as another word.

Example

```
Happy → Joyful
```

Both express happiness.

# Types of Synonyms

```
Synonyms
│
├── Exact Synonyms
├── Near Synonyms
└── Contextual Synonyms
```

---

# 1. Exact Synonyms

Words that can replace each other in most situations.

Examples

```
Begin → Start

Finish → Complete

Reply → Answer
```

---

# 2. Near Synonyms

Words with similar meanings but slight differences.

Example

```
Slim

Thin
```

Both refer to low body weight, but **Slim** often has a positive meaning while **Thin** can be neutral or negative depending on context.

---

Another Example

```
Look

Glance

Stare

Peek
```

All involve seeing, but each has a different nuance.

---

# 3. Contextual Synonyms

Some words are synonyms only in certain contexts.

Example

```
Bright
```

Meaning 1

```
Intelligent
```

Meaning 2

```
Shining
```

The correct synonym depends on the sentence.

# Choosing the Correct Synonym

Always read the sentence first.

Example

```
He gave a bright answer.
```

Correct synonym

```
Intelligent
```

---

Example

```
The bright sun was shining.
```

Correct synonym

```
Radiant
```

# Commonly Confused Synonyms

---

## Big vs Large

Generally interchangeable.

```
Big house

Large house
```

---

## Speak vs Talk

```
Speak

↓

More Formal
```

```
Talk

↓

More Informal
```

---

## Ask vs Request

```
Ask

↓

Informal
```

```
Request

↓

Formal
```

---

## End vs Finish

Both mean to complete something.

```
The movie ended.

I finished my homework.
```

# Interview Corner

### Q1. What is a synonym?

A synonym is a word that has the same or nearly the same meaning as another word.

---

### Q2. Why are synonyms important?

They improve vocabulary, reading comprehension, communication, and help solve aptitude questions quickly.

---

### Q3. How can I improve my synonym vocabulary?

- Learn 10–20 words daily.
- Revise regularly.
- Learn words in groups.
- Use flashcards.
- Read newspapers, books, and articles.

---

# GATE 80/20 Summary

✅ Learn the **500–1000 most common vocabulary words** instead of memorizing rare words.

✅ Group similar words together for faster recall.

✅ Focus on words frequently asked in aptitude exams.

✅ Revise daily using flashcards or spaced repetition.

✅ Solve vocabulary-based MCQs regularly to reinforce learning.
