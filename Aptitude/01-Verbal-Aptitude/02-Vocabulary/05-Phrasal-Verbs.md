# Phrasal Verbs

## Definition

A **Phrasal Verb** is a combination of:

```
Verb + Preposition
```

or

```
Verb + Adverb
```

or

```
Verb + Adverb + Preposition
```

that functions as a single verb with a meaning that is often different from the original verb.

---

## Structure

```
Verb + Adverb
```

Examples

```
Give up
```

```
Wake up
```

```
Take off
```

---

```
Verb + Preposition
```

Examples

```
Look after
```

```
Care for
```

```
Believe in
```

---

```
Verb + Adverb + Preposition
```

Examples

```
Put up with
```

```
Look forward to
```

```
Get away with
```

---

# Why Phrasal Verbs Are Difficult

The meaning usually **cannot be guessed** from the individual words.

Example

```
Give

↓

Provide
```

```
Up

↓

Direction
```

But

```
Give up

↓

Quit
```

---

## Types of Phrasal Verbs

```
Phrasal Verbs
│
├── Intransitive
├── Transitive
│     ├── Separable
│     └── Inseparable
└── Three-word Phrasal Verbs
```

---

# 1. Intransitive Phrasal Verbs

They **do not take an object**.

Structure

```
Subject + Phrasal Verb
```

Examples

```
The plane took off.
```

```
He woke up.
```

```
Prices went up.
```

---

# 2. Transitive Phrasal Verbs

They require an object.

Structure

```
Subject + Phrasal Verb + Object
```

Example

```
She looked after the child.
```

---

## A. Separable Phrasal Verbs

The object may come

```
Between the verb and particle
```

or

```
After the complete phrasal verb.
```

Example

```
Turn off the light.
```

```
Turn the light off.
```

Both are correct.

---

### Pronoun Rule (Very Important)

If the object is a **pronoun**, it **must** come between the verb and the particle.

Correct

```
Turn it off.
```

Incorrect

```
Turn off it.
```

---

More Examples

Correct

```
Pick it up.
```

Incorrect

```
Pick up it.
```

# 3. Inseparable Phrasal Verbs

The object **always comes after** the complete phrasal verb.

Correct

```
Look after the baby.
```

Incorrect

```
Look the baby after.
```

---

More Examples

```
Run into a friend.
```

```
Believe in yourself.
```

```
Deal with problems.
```

# Common Mistakes

## Mistake 1

Incorrect

```
Turn off it.
```

Correct

```
Turn it off.
```

---

## Mistake 2

Incorrect

```
Look the baby after.
```

Correct

```
Look after the baby.
```

---

## Mistake 3

Using literal meanings.

Example

```
Give up

≠ Give + Up

✓ Quit
```

---

## Mistake 4

Confusing

```
Look for

(Search)
```

with

```
Look after

(Take care of)
```

# GATE 80/20 Summary

✅ Master the **50–100 most common phrasal verbs**.

✅ Learn whether a phrasal verb is:
- Intransitive
- Transitive (Separable)
- Transitive (Inseparable)

✅ Remember the **Pronoun Rule**:
- ✔️ Turn **it** off.
- ❌ Turn off **it**.

✅ Learn phrasal verbs by **meaning groups** (Look, Take, Get, Give, Put, Come, Go) instead of memorizing random lists.
