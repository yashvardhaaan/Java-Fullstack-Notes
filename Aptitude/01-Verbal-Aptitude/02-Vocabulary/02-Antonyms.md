# What is an Antonym?

An **Antonym** is a word that has the **opposite meaning** of another word.

Example

```
Hot → Cold
```

```
Success → Failure
```

# Types of Antonyms

```
Antonyms
│
├── Gradable
├── Complementary
└── Relational
```

---

# 1. Gradable Antonyms

These represent opposite ends of a scale.

Examples

```
Hot ←→ Cold

Big ←→ Small

Young ←→ Old

Fast ←→ Slow
```

There can be intermediate values.

Example

```
Hot

↓

Warm

↓

Cool

↓

Cold
```

---

# 2. Complementary Antonyms

One excludes the other.

Examples

```
Alive ←→ Dead

True ←→ False

Present ←→ Absent

Legal ←→ Illegal
```

No middle state exists in most contexts.

---

# 3. Relational Antonyms

One word exists only because of the other.

Examples

```
Teacher ←→ Student

Buy ←→ Sell

Parent ←→ Child

Employer ←→ Employee

Above ←→ Below
```

# Prefixes That Form Antonyms

Learning prefixes helps you understand hundreds of opposite words.

| Prefix | Meaning | Example |
|--------|---------|----------|
| Un- | Not | Happy → Unhappy |
| In- | Not | Correct → Incorrect |
| Im- | Not | Possible → Impossible |
| Ir- | Not | Regular → Irregular |
| Il- | Not | Legal → Illegal |
| Dis- | Opposite | Honest → Dishonest |
| Non- | Absence | Sense → Nonsense |
| Mis- | Wrongly | Understand → Misunderstand |

# Interview Corner

### Q1. What is an antonym?

An antonym is a word that has the opposite meaning of another word.

---

### Q2. How can I improve my antonym vocabulary?

- Learn words in pairs.
- Understand prefixes like **un-**, **dis-**, **im-**, and **non-**.
- Revise regularly.
- Solve vocabulary MCQs.

---

### Q3. Why are antonyms important in aptitude exams?

Antonym questions test vocabulary, comprehension, and the ability to understand context quickly.

---

# GATE 80/20 Summary

✅ Learn the **500–1000 most common opposite-word pairs**.

✅ Master common prefixes that create antonyms.

✅ Focus on high-frequency exam words instead of rare vocabulary.

✅ Practice daily through MCQs and flashcards.

✅ Revise regularly using word families and opposite pairs.
