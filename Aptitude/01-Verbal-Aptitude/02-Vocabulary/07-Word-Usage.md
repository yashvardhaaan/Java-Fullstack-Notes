# Word Usage

## Definition

**Word Usage** refers to using the correct word in the correct context according to its meaning, grammar, collocation, and style.

Correct word usage improves clarity, accuracy, and readability.

---

# Factors Affecting Word Usage

```
Word Usage
│
├── Meaning
├── Context
├── Grammar
├── Collocation
├── Register
└── Precision
```

# 1. Meaning

Choose the word that conveys the intended meaning.

### Incorrect

```
He consumed a decision.
```

### Correct

```
He made a decision.
```

### Incorrect


# 4. Collocations

A **collocation** is a natural combination of words that native speakers commonly use.

## Common Verb + Noun Collocations

| Correct | Incorrect |
|----------|-----------|
| Make a decision | Do a decision |
| Make a mistake | Do a mistake |
| Take a break | Make a break |
| Give advice | Offer an advice |
| Pay attention | Give attention |
| Catch a bus | Take a catch |
| Keep a promise | Maintain a promise |

---

## Common Adjective + Noun Collocations

| Correct | Incorrect |
|----------|-----------|
| Heavy rain | Strong rain |
| Strong coffee | Powerful coffee |
| Fast food | Quick food |
| High temperature | Tall temperature |
| Deep sleep | Strong sleep |

---

## Common Verb + Preposition Collocations

| Correct | Incorrect |
|----------|-----------|
| Depend on | Depend to |
| Listen to | Listen |
| Believe in | Believe on |
| Apply for | Apply to (for a job) |
| Agree with | Agree to (a person) |

> **Note**
>
> - **Agree with** → a person or an opinion
> - **Agree to** → a proposal, terms, or a plan

Examples

```
I agree with you.
```

```
She agreed to the proposal.
```

# 5. Register (Formal vs Informal)

Different situations require different vocabulary.

| Informal | Formal |
|----------|--------|
| Ask | Request |
| Buy | Purchase |
| Help | Assist |
| Get | Obtain |
| Start | Commence |
| End | Conclude |
| Tell | Inform |

### Example

Informal

```
Can you help me?
```

Formal

```
Could you assist me?
```

# Frequently Misused Words

## Say vs Tell

| Say | Tell |
|-----|------|
| Focuses on words spoken | Requires an indirect object |

Examples

```
She said, "Hello."
```

```
She told me the truth.
```

---

## Speak vs Talk

| Speak | Talk |
|-------|------|
| More formal | More informal |

Examples

```
He spoke at the conference.
```

```
We talked for an hour.
```

---

## Hear vs Listen

| Hear | Listen |
|------|---------|
| Happens naturally | Requires attention |

Examples

```
I heard a noise.
```

```
Please listen carefully.
```

---

## See vs Watch vs Look

| Word | Usage |
|------|-------|
| See | Notice naturally |
| Look | Direct your eyes |
| Watch | Observe for some time |

Examples

```
I saw a rainbow.
```

```
Look at the board.
```

```
We watched a movie.
```

---

## Win vs Beat

| Win | Beat |
|-----|------|
| Win a prize/game | Beat an opponent |

Examples

```
India won the match.
```

```
India beat Australia.
```

---

## Learn vs Teach

| Learn | Teach |
|--------|--------|
| Receive knowledge | Give knowledge |

Examples

```
I learned Java.
```

```
She teaches mathematics.
```

---

## Remember vs Remind

| Remember | Remind |
|-----------|--------|
| Recall | Help someone remember |

Examples

```
I remembered the answer.
```

```
Please remind me tomorrow.
```

# GATE 80/20 Summary

✅ Focus on high-frequency collocations such as **make a decision**, **pay attention**, and **take a break**.

✅ Memorize commonly misused expressions:
- Discuss (not *discuss about*)
- Return (not *return back*)
- Enter (not *enter into*)
- Repeat (not *repeat again*)

✅ Learn context-based verb pairs:
- Hear / Listen
- See / Look / Watch
- Win / Beat
- Learn / Teach
- Say / Tell

Mastering these patterns covers the majority of word-usage questions in aptitude and placement tests.
