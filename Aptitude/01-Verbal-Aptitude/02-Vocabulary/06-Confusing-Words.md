# Confusing Words

## Definition

**Confusing Words** are words that look similar, sound similar, or have related meanings but are used differently depending on the context.

These are frequently tested in grammar, vocabulary, sentence correction, and reading comprehension.

# Accept vs Except

| Word | Meaning |
|------|---------|
| Accept | To receive or agree |
| Except | Excluding |

### Examples

```
I accepted the invitation.
```

```
Everyone came except Rahul.
```

---

# Affect vs Effect

| Word | Meaning | Part of Speech |
|------|---------|----------------|
| Affect | To influence | Verb |
| Effect | Result | Noun |

### Examples

```
Lack of sleep affects health.
```

```
The medicine had no effect.
```

---

### Memory Trick

```
Affect

↓

Action (Verb)
```

```
Effect

↓

End Result (Noun)
```
