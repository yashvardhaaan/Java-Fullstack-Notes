# What is an Idiom?

An **Idiom** is a group of words whose meaning is **different from the literal meaning** of the individual words.

Example

```
Break the ice
```

Literal Meaning

```
To break frozen water.
```

Actual Meaning

```
To start a conversation or reduce tension.
```

---

# What is a Phrase?

A **Phrase** is a group of words that acts as a unit but **does not contain both a subject and a verb**.

Example

```
In the morning

On time

At home
```

---

# Idiom vs Phrase

| Idiom | Phrase |
|-------|---------|
| Figurative Meaning | Literal Meaning |
| Meaning cannot be guessed directly | Meaning is usually clear |
| Break the ice | At home |
| Hit the sack | In the evening |

# Tips to Learn Idioms

### Learn with Stories

Instead of memorizing:

```
Piece of Cake

↓

Easy
```

Imagine

```
A delicious cake that is easy to eat.
```

---

### Group Similar Idioms

```
Happy

↓

On Cloud Nine
```

```
Successful

↓

Hit the Jackpot
```

---

### Practice in Sentences

Don't memorize only the meaning.

Use it.

Example

```
Preparing for the interview was not a piece of cake.
```

# Interview Corner

### Q1. What is an idiom?

An idiom is a group of words whose meaning is different from the literal meaning of the individual words.

---

### Q2. What is the difference between an idiom and a phrase?

- **Idiom:** Has a figurative meaning.
- **Phrase:** Usually has a literal meaning and functions as a part of a sentence.

---

### Q3. How can I remember idioms easily?

- Learn them in context.
- Use them in sentences.
- Group similar idioms together.
- Revise regularly using flashcards.
