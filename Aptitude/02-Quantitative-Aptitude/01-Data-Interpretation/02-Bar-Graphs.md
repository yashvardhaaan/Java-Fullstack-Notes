# Bar Graphs

## Definition

A **Bar Graph (Bar Chart)** is a graphical representation of categorical data using rectangular bars of equal width. The height (or length) of each bar is proportional to the value it represents.

Bar graphs make it easy to compare quantities across different categories.

---

# Why Learn This?

Bar graphs are one of the most widely used visualization techniques in the real world.

Applications include:

- **Business Analytics** – Compare sales, revenue, profits, and customer growth.
- **Software Engineering** – Visualize API response times, server loads, bug counts, and feature usage.
- **Data Science** – Compare datasets and identify trends.
- **Finance** – Analyze quarterly earnings, investments, and expenses.
- **Healthcare** – Compare patient statistics and disease prevalence.
- **Education** – Compare student performance across subjects or classes.
- **Government & Research** – Present census data, survey results, and economic indicators.

---

# 1. Vertical Bar Graph

Bars extend vertically.

Used when categories are placed on the X-axis.

Example:

```
Sales

250 |
200 |       █
150 |   █   █
100 | █ █   █
 50 | █ █ █ █
     A B C D
```

---

# 2. Horizontal Bar Graph

Bars extend horizontally.

Useful when category names are long.

Example:

```
Product A ███████

Product B ███████████

Product C █████
```

---

# 3. Double Bar Graph

Compares two related datasets.

Example:

| Product | 2024 | 2025 |
|---------|-----:|-----:|
| A | 120 | 150 |
| B | 140 | 180 |

---

# 4. Multiple Bar Graph

Compares three or more datasets.

Example:

```
2023 ███

2024 █████

2025 ███████
```

---

# 5. Stacked Bar Graph

Each bar is divided into sections representing different components.

Useful for showing both:

- Total value
- Individual contribution

# Important Formulae

## Total

```
Total = Sum of Values
```

---

## Average

```
Average = Sum of Values / Number of Values
```

---

## Difference

```
Difference = Larger − Smaller
```

---

## Percentage

```
(Part / Total) × 100
```

---

## Percentage Increase

```
((New − Old) / Old) × 100
```

---

## Ratio

```
A : B = A / B
```

# Shortcuts & Tricks

### 1. Read the Scale First

Many mistakes occur because students ignore the graph's scale.

Example

```
1 Unit = 100
```

A bar reaching 5 units represents:

```
500
```

---

### 2. Compare Heights First

Many comparison questions can be answered without calculations.

---

### 3. Estimate Before Calculating

Approximation helps eliminate incorrect options quickly.

---

### 4. Check Units

Values may be in:

- Thousands
- Millions
- Percentage
- Kilograms
- Dollars

Always verify the unit before solving.

---

### 5. Use Mental Math

Fast addition, subtraction, and percentages reduce solving time.

# Solved Example

The following bar graph represents monthly sales.

| Month | Sales |
|--------|------:|
| Jan | 120 |
| Feb | 150 |
| Mar | 180 |
| Apr | 160 |

---

## Example 1

Find the highest sales.

Solution

```
Maximum = 180
```

Answer

```
March
```

---

## Example 2

Find total sales.

Solution

```
120 + 150 + 180 + 160

= 610
```

Answer

```
610
```

---

## Example 3

Find average sales.

Solution

```
610 / 4

= 152.5
```

Answer

```
152.5
```

---

## Example 4

Difference between March and January.

Solution

```
180 − 120

= 60
```

Answer

```
60
```

# Practice Questions

Use the following data.

| Product | Sales |
|---------|------:|
| A | 120 |
| B | 180 |
| C | 150 |
| D | 200 |

---

## Q1

Which product has the highest sales?

**Answer**

```
D
```

---

## Q2

Find the total sales.

**Answer**

```
120 + 180 + 150 + 200

= 650
```

---

## Q3

Find the average sales.

**Answer**

```
650 / 4

= 162.5
```

---

## Q4

Difference between Product D and Product A.

**Answer**

```
200 − 120

= 80
```

---

## Q5

Find the ratio of Product B to Product C.

**Answer**

```
180 : 150

= 6 : 5
```
