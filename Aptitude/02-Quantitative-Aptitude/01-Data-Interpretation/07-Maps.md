# Maps

## Definition

**Map Data Interpretation (Map DI)** involves analyzing geographical maps that contain numerical information such as population, rainfall, production, transportation routes, resource distribution, distances, or regional statistics.

Unlike traditional maps used for navigation, Map DI combines **geography with quantitative analysis**, requiring you to interpret spatial and numerical data together.

---

# Why Learn This?

Maps are used whenever decisions depend on **location-based data**.

Applications include:

- **Logistics & Supply Chain** – Plan delivery routes, warehouse locations, and transportation costs.
- **Software Engineering** – Power navigation systems like Google Maps, food delivery apps, ride-sharing platforms, and location-based services.
- **GIS (Geographic Information Systems)** – Analyze land use, natural resources, and urban planning.
- **Business Analytics** – Identify sales performance across regions and optimize market expansion.
- **Government & Public Planning** – Plan roads, railways, hospitals, disaster management, and public infrastructure.
- **Agriculture & Environment** – Study rainfall, crop production, soil quality, and climate patterns.

```

```

---

```

```

---

## Time

```
Time = Distance / Speed
```

---

## Average

```

```

---

## Percentage

(Part / Total) × 100

## Ratio

A : B
```

# Solved Example

A map has the following scale.

```
1 cm = 20 km
```

Distances on the map

| Route | Map Distance |
|--------|-------------:|
| A → B | 3 cm |
| B → C | 5 cm |
| A → C | 6 cm |

---

## Example 1

Find the actual distance from A to B.

Solution

```
3 × 20

=60 km
```

Answer

```
60 km
```

---

## Example 2

Find the shortest route from A to C.

Routes

```
Direct

=6 cm

=120 km
```

Via B

```
3 + 5

=8 cm

=160 km
```

Answer

```
Direct Route

120 km
```

---

## Example 3

A vehicle travels from A to C at **60 km/h**.

Find the travel time.

Solution

```
Distance

=120 km
```

```
Time

=120/60

=2 hours
```

Answer

```
2 hours
```

| Route | Map Distance |
|--------|-------------:|
| A → B | 4 cm |

---

## Q1

Find the actual distance from A to B.

**Answer**

```
4 × 15

=60 km
```

---

## Q2

Find the distance from B to C.

**Answer**

```
3 × 15

=45 km
```

---

## Q3

Find the direct distance from A to C.

**Answer**

```
6 × 15

=90 km
```

---

## Q4

A vehicle travels from A to C at **45 km/h**.

Find the travel time.

**Answer**

```
90/45

=2 hours
```

---

Which is the shorter route from A to C?

- Direct
- Via B

**Answer**

```
Direct Route

90 km

Via B

105 km
