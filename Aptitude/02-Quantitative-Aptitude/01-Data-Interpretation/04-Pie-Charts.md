# Pie Charts

## Definition

A **Pie Chart (Circle Chart)** is a circular graph divided into sectors, where each sector represents a category's proportion of the whole. The size of each sector is directly proportional to its value.

A complete pie chart always represents **100%** or **360°**.

---

# Why Learn This?

Pie charts are widely used to visualize how a whole is divided among different categories.

Applications include:

- **Business Analytics** – Analyze market share, product sales distribution, and revenue contribution.
- **Software Engineering** – Visualize API usage, browser usage, operating system distribution, and error categories.
- **Finance** – Show budget allocation, investment portfolios, and expense breakdowns.
- **Healthcare** – Represent disease distribution, patient demographics, and treatment outcomes.
- **Government & Research** – Display census statistics, election results, and survey responses.
- **Marketing** – Analyze customer segmentation, campaign performance, and advertising channels.

# Basic Concepts

A pie chart always represents the complete dataset.

```
Whole Circle = 360°

or

Whole Circle = 100%
```

Each sector represents

```
Sector Size

↓

Category Share
```

---

# Important Formulae

## Central Angle

```
(Value / Total) × 360°
```

---

## Percentage

```
(Value / Total) × 100
```

---

## Value from Percentage

```
(Total × Percentage) / 100
```

---

## Value from Angle

```
(Total × Angle) / 360
```

---

# Shortcuts & Tricks

### 1. Memorize Common Angles

| Angle | Percentage |
|-------:|-----------:|
| 360° | 100% |
| 180° | 50% |
| 120° | 33.33% |
| 90° | 25% |
| 72° | 20% |
| 60° | 16.67% |
| 45° | 12.5% |
| 36° | 10% |
| 18° | 5% |

---

### 2. Convert Percentages Mentally

Know these instantly:

```
50% = 1/2

25% = 1/4

20% = 1/5

10% = 1/10

12.5% = 1/8

33.33% = 1/3
```

---

### 3. Check the Total

Ensure that

```
Total Angles = 360°

OR

Total Percentages = 100%
```

---

### 4. Compare Sector Sizes First

The largest sector represents the largest value.

The smallest sector represents the smallest value.

---

### 5. Use Ratios Instead of Actual Values

Many comparison questions can be solved directly using angles or percentages without calculating actual values.

# Solved Example

A company's total annual sales are **1000 units**.

| Product | Percentage |
|----------|-----------:|
| A | 40% |
| B | 30% |
| C | 20% |
| D | 10% |

---

## Example 1

Find Product A sales.

Solution

```
(40 × 1000)/100

=400
```

Answer

```
400
```

---

## Example 2

Find the central angle of Product B.

Solution

```
(30 × 360)/100

=108°
```

Answer

```
108°
```

---

## Example 3

Find the ratio of Product A to Product C.

Solution

```
40 : 20

=2 : 1
```

Answer

```
2 : 1
```

---

## Example 4

Difference between Product B and Product D.

Solution

```
30% − 10%

=20%
```

Actual Difference

```
20% of 1000

=200
```

Answer

```
200
```

# Practice Questions

A company's total employees = **500**

| Department | Percentage |
|------------|-----------:|
| HR | 10% |
| IT | 40% |
| Sales | 30% |
| Finance | 20% |

---

## Q1

How many employees work in IT?

**Answer**

```
(40 × 500)/100

=200
```

---

## Q2

Find the central angle of Finance.

**Answer**

```
(20 × 360)/100

=72°
```

---

## Q3

Which department has the largest share?

**Answer**

```
IT
```

---

## Q4

Find the ratio of Sales to HR.

**Answer**

```
30 : 10

=3 : 1
```

---

## Q5

How many more employees work in IT than HR?

**Answer**

```
40% − 10%

=30%

30% of 500

=150
```

| Value | (Total × Percentage) ÷ 100 |

# GATE 80/20 Summary

✅ Remember **360° = 100%**.

✅ Memorize common angle–percentage conversions (90°, 180°, 72°, 36°).

✅ Use ratios of angles or percentages directly for comparison questions.

✅ Verify that all sector percentages add up to **100%** (or **360°**).

✅ Most questions revolve around **percentage, angle, ratio, and actual value**.
