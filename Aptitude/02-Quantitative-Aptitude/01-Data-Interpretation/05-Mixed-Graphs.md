# Mixed Graphs

## Definition

**Mixed Graph Data Interpretation** consists of questions where **two or more different types of graphs** are used together to represent data. You need to analyze the relationship between them to answer the questions.

Common combinations include:

- Bar Graph + Line Graph
- Table + Pie Chart
- Line Graph + Pie Chart
- Bar Graph + Table
- Pie Chart + Bar Graph

Mixed Graphs test both **interpretation skills** and **calculation speed**.

---

# Why Learn This?

Mixed Graphs are widely used because a single chart often cannot represent all the required information.

Applications include:

- **Business Intelligence** – Dashboards combining revenue, profit, customer growth, and market share.
- **Software Engineering** – Monitoring server performance using CPU utilization, memory usage, request count, and response time together.
- **Data Analytics** – Interactive dashboards in Power BI, Tableau, and Excel.
- **Finance** – Comparing income, expenses, investments, and portfolio allocation.
- **Healthcare** – Patient demographics combined with treatment statistics.
- **Research & Government** – Census reports, economic reports, and survey analysis.

# Shortcuts & Tricks

### 1. Read Every Graph Title

Do not assume all charts represent the same data.

---

### 2. Check Units

One graph may use

```
Thousands

Millions

Percentages

Degrees
```

Always verify before calculating.

---

### 3. Identify Relationships

Ask yourself:

- Does one graph provide totals?
- Does another provide percentages?
- Which graph gives actual values?

---

### 4. Solve One Graph at a Time

Avoid reading all graphs simultaneously.

---

### 5. Write Intermediate Values

For multi-step questions, note down intermediate calculations to reduce mistakes.

# Solved Example

A company has:

### Bar Graph

| Year | Revenue ($) |
|------|------------:|
| 2024 | 500 |
| 2025 | 700 |

### Pie Chart (2025 Revenue Distribution)

| Department | Share |
|------------|------:|
| IT | 40% |
| HR | 20% |
| Sales | 25% |
| Finance | 15% |

---

## Example 1

Find IT Revenue.

Solution

```
40% of 700

=(40×700)/100

=280
```

Answer

```
280
```

---

## Example 2

Revenue Increase

Solution

```
700−500

=200
```

Answer

```
200
```

---

## Example 3

Percentage Increase

Solution

```
((700−500)/500)×100

=(200/500)×100

=40%
```

Answer

```
40%
```

# Practice Questions

The total company revenue is **$800**.

Revenue Distribution:

| Department | Percentage |
|------------|-----------:|
| IT | 35% |
| Sales | 30% |
| HR | 20% |
| Finance | 15% |

Revenue last year = **$650**

---

## Q1

Find IT Revenue.

**Answer**

```
35% of 800

=280
```

---

## Q2

Find Sales Revenue.

**Answer**

```
30% of 800

=240
```

---

## Q3

Find Revenue Increase.

**Answer**

```
800−650

=150
```

---

## Q4

Find Percentage Increase.

**Answer**

```
((800−650)/650)×100

≈23.08%
```

---

## Q5

Which department contributes the least?

**Answer**

```
Finance
```

# GATE 80/20 Summary

✅ Read the title and units of **every graph** before solving.

✅ Identify which graph provides **totals** and which provides **distribution**.

✅ Convert percentages into actual values only when required.

✅ Solve one graph at a time, then combine the information.

✅ Most mistakes occur due to **mixing units or interpreting the wrong graph**.
