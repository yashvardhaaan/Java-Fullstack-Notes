# 2D Plots

## Definition

**2D Plots (Two-Dimensional Plots)** are graphical representations used to display the relationship between two variables on a two-dimensional coordinate system.

One variable is plotted on the **X-axis (Horizontal Axis)** and the other on the **Y-axis (Vertical Axis)**.

2D plots help identify:

- Trends
- Relationships
- Correlations
- Patterns
- Distribution of data

---

# Why Learn This?

2D plots are one of the most widely used visualization techniques for understanding relationships between variables.

Applications include:

- **Software Engineering** – Monitor CPU usage vs time, API latency, memory consumption, and application performance.
- **Data Science & Machine Learning** – Explore datasets, detect patterns, identify correlations, and visualize model outputs.
- **Business Analytics** – Analyze sales trends, customer growth, product performance, and revenue changes.
- **Finance** – Track stock prices, investment returns, and market trends.
- **Healthcare** – Monitor patient recovery, heart rate, blood pressure, and disease progression.
- **Scientific Research** – Visualize experimental results and compare observations.

# Cartesian Coordinate System

A 2D plot consists of two perpendicular axes.

```
                Y-Axis
                  ↑
          II      │      I
                  │
------------------O----------------→ X-Axis
                  │
          III     │      IV
                  │
                  ↓
```

The point where both axes meet is called the

```
Origin (0,0)
```

Represents individual observations as points.

Example

```
Y

8 |          ●

6 |      ●

4 |   ●

  +----------------------→ X
```

Used to study

- Correlation
- Clustering
- Outliers

---

# 2. Line Plot

Data points are connected using straight lines.

Useful for

- Growth
- Trend Analysis
- Time Series

---

# 3. Area Plot

Area under the line is filled.

Useful for

- Cumulative Growth
- Total Usage
- Resource Consumption

---

# 4. Dot Plot

Each value is represented by a dot.

Useful for

- Small datasets
- Frequency comparison

---

# 5. Bubble Plot

Each point has

- X coordinate
- Y coordinate
- Bubble Size

Used to visualize three variables simultaneously.

# Correlation

## Positive Correlation

Both variables increase together.

```
●

   ●

      ●

          ●
```

Example

```
Study Hours ↑

Marks ↑
```

---

## Negative Correlation

One variable increases while the other decreases.

```
●

      ●

           ●

                ●
```

Example

```
Speed ↑

Travel Time ↓
```

---

## No Correlation

No clear relationship exists.

```
●      ●

    ●

         ●

 ●
```

# Important Formulae

## Average

```
Average = Sum / Number of Values
```

---

## Percentage Change

```
((New − Old) / Old) × 100
```

---

## Difference

```
Larger − Smaller
```

---

## Slope (Basic)

```
Slope = Rise / Run

= ΔY / ΔX
```

A larger slope indicates a faster rate of change.

# Shortcuts & Tricks

### 1. Read Axis Labels Carefully

Always identify what each axis represents before interpreting the graph.

---

### 2. Check the Scale

Unequal scales can lead to incorrect conclusions.

---

### 3. Look at the Overall Pattern

Before calculating, determine whether the graph shows:

- Growth
- Decline
- Stability
- Randomness

---

### 4. Identify Outliers

Points far from the general pattern may indicate unusual observations.

---

### 5. Compare Slopes

Steeper lines represent faster changes.
