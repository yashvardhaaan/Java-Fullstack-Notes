# Problem 1 – Table

The following table shows the number of books sold by a bookstore.

| Month | Books Sold |
|-------|-----------:|
| Jan | 250 |
| Feb | 300 |
| Mar | 280 |
| Apr | 350 |
| May | 320 |

### Q1

Which month had the highest sales?

**Answer**

```
April
```

---

### Q2

Total books sold?

**Answer**

```
250+300+280+350+320

=1500
```

---

### Q3

Average books sold?

**Answer**

```
1500/5

=300
```

# Problem 2 – Bar Graph

A company's quarterly profits ($ in thousands) are:

| Quarter | Profit ($) |
|---------|-----------:|
| Q1 | 120 |
| Q2 | 160 |
| Q3 | 140 |
| Q4 | 180 |

### Q1

Which quarter had the highest profit?

**Answer**

```
Q4
```

---

### Q2

Difference between Q4 and Q2?

**Answer**

```
180−160

=20
```

---

### Q3

Average quarterly profit?

**Answer**

```
120+160+140+180

=600

600/4

=150
```

# Quick Revision Sheet

| Concept | Formula |
|----------|---------|
| Total | Sum of Values |
| Average | Sum ÷ Count |
| Percentage | (Part ÷ Total) × 100 |
| Difference | Larger − Smaller |
| Percentage Increase | ((New−Old) ÷ Old) × 100 |
| Distance | Scale × Map Length |
| Time | Distance ÷ Speed |
| Speed | Distance ÷ Time |

---

# GATE 80/20 Summary

✅ Read the title, labels, units, and scale before solving.

✅ Organize data into tables whenever needed.

✅ Memorize the formulas for **average, percentage, ratio, distance, and percentage increase**.

✅ Practice identifying trends, comparisons, and distributions across different graph types.

✅ Most Data Interpretation questions test **speed, calculation accuracy, and logical interpretation** rather than advanced mathematics.
