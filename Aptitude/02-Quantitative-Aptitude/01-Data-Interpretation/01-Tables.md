# Tables

## Definition

**Table Data Interpretation (DI)** is the process of analyzing numerical data presented in rows and columns to answer questions involving calculations, comparisons, trends, and logical reasoning.

Tables are one of the most common Data Interpretation topics in placement tests, GATE Aptitude, CAT, Banking, SSC, and other competitive exams.

---

# Why Learn This?

- Frequently asked in GATE Aptitude, CAT, Banking, SSC, and placement tests.
- Forms the foundation for all Data Interpretation questions.
- Tests calculation speed, accuracy, and logical analysis.

# What is a Table?

A table organizes data into **rows** and **columns** for easier comparison.

Example:

| Student | Maths | Science | English |
|---------|------:|--------:|--------:|
| A | 85 | 90 | 80 |
| B | 78 | 82 | 88 |
| C | 91 | 87 | 85 |

Rows represent individual records.

Columns represent categories or attributes.

# Types of Tables

## 1. Simple Table

Contains one category of information.

Example

| Product | Sales |
|---------|------:|
| A | 120 |
| B | 150 |
| C | 180 |

---

## 2. Double Table

Compares two different categories.

| Product | 2024 | 2025 |
|---------|-----:|-----:|
| A | 120 | 145 |
| B | 160 | 190 |

---

## 3. Multi-variable Table

Contains multiple attributes.

| Product | Sales | Profit | Employees |
|---------|------:|-------:|----------:|
| A | 120 | 30 | 15 |
| B | 180 | 45 | 18 |

# Important Formulae

## Total

```
Total = Sum of all values
```

---

## Average

```
Average = Sum of Values / Number of Values
```

---

## Percentage

```
Percentage = (Part / Total) × 100
```

---

## Percentage Increase

```
((New − Old) / Old) × 100
```

---

## Percentage Decrease

```
((Old − New) / Old) × 100
```

---

## Ratio

```
A : B = A / B
```

---

## Difference

```
Difference = Larger Value − Smaller Value
```

# Solved Example 1

| Company | Sales |
|---------|------:|
| A | 120 |
| B | 180 |
| C | 200 |

Find the total sales.

Solution

```
120 + 180 + 200

= 500
```

Answer

```
500
```

---

# Solved Example 2

| Student | Marks |
|---------|------:|
| A | 70 |
| B | 80 |
| C | 90 |

Find the average marks.

Solution

```
(70 + 80 + 90) / 3

= 240 / 3

= 80
```

Answer

```
80
```

---

# Solved Example 3

| Year | Production |
|------|-----------:|
| 2024 | 500 |
| 2025 | 650 |

Find the percentage increase.

Solution

```
Increase = 650 − 500

=150
```

```
Percentage

=(150/500)×100

=30%
```

Answer

```
30%
```

# Practice Questions

Use the following table.

| Product | 2024 | 2025 |
|---------|-----:|-----:|
| A | 100 | 120 |
| B | 150 | 180 |
| C | 200 | 220 |

---

## Q1

Find the total sales in 2024.

Answer

```
450
```

---

## Q2

Find the average sales in 2025.

Answer

```
(120+180+220)/3

=520/3

≈173.33
```

---

## Q3

Which product had the highest sales in 2025?

Answer

```
Product C
```

---

## Q4

Find the increase in Product B.

Answer

```
180−150=30
```

---

## Q5

Find the percentage increase in Product A.

Solution

```
(20/100)×100

=20%
```

Answer

```
20%
```
