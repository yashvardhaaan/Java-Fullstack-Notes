# Line Graphs

## Definition

A **Line Graph (Line Chart)** is a graphical representation of data in which individual data points are connected using straight lines. It is primarily used to show **changes, trends, and patterns over time**.

Line graphs are ideal for visualizing continuous data such as monthly sales, stock prices, website traffic, temperature, or population growth.

---

# Why Learn This?

Line graphs are one of the most commonly used visualizations for analyzing trends over time.

Applications include:

- **Software Engineering** – Monitor CPU usage, memory consumption, API response time, server uptime, and application performance.
- **Data Science & Analytics** – Analyze trends, forecast future values, and compare datasets over time.
- **Finance** – Track stock prices, investment growth, exchange rates, and company revenue.
- **Healthcare** – Monitor patient recovery, disease spread, and hospital admissions.
- **Business Intelligence** – Analyze monthly sales, customer growth, and marketing performance.
- **Weather Forecasting** – Study temperature, rainfall, humidity, and climate trends.
- **Scientific Research** – Observe experimental results and continuous measurements.

# 1. Simple Line Graph

Represents a single dataset.

Example

```
Sales

200 |        ●
150 |    ●

      Jan Feb Mar Apr
```

---

# 2. Double Line Graph

Compares two datasets.

Example

```
Company A  ●──●──●

Company B  ▲──▲──▲
```

Used for:

- Company comparison
- Sales comparison
- Population comparison

---

# 3. Multiple Line Graph

Displays three or more datasets simultaneously.

Useful for comparing multiple products, companies, or countries.

---

# 4. Area Line Graph

The area below the line is shaded.

Used to emphasize total quantity over time.

# Important Formulae

## Total

```
Total = Sum of Values
```

---

## Average

```
Average = Sum / Number of Values
```

---

## Difference

```
Difference = Larger − Smaller
```

---

## Percentage Increase

```
((New − Old) / Old) × 100
```

---

## Percentage Decrease

```
((Old − New) / Old) × 100
```

---

## Growth Rate

```
Growth = Current − Previous
```

---

```
      ●
    ●
  ●
●
```

---


Represents no significant change.

```
   ●
 ●
      ●
   ●
```

# Shortcuts & Tricks

### 1. Read the Scale Carefully

A small change in scale can significantly change the values.

---

### 2. Observe the Overall Trend First

Determine whether the graph shows:

- Increasing
- Decreasing
- Constant
- Fluctuating

before solving individual questions.

---

### 3. Identify Peaks and Valleys

- Highest point = Maximum value
- Lowest point = Minimum value

---

### 4. Estimate Before Calculating

Approximation is often sufficient to eliminate incorrect options.

---

### 5. Compare Slopes

A steeper slope indicates a faster rate of increase or decrease.

# Practice Questions

Use the following data.

| Month | Revenue ($) |
|--------|------------:|
| Jan | 80 |
| Feb | 100 |
| Mar | 120 |
| Apr | 110 |
| May | 140 |

---

## Q1

Which month has the highest revenue?

**Answer**

```
May
```

---

## Q2

Find the increase from January to May.

**Answer**

```
140 − 80 = 60
```

---

## Q3

Find the average revenue.

**Answer**

```
(80+100+120+110+140)

=550

550/5

=110
```

---

## Q4

What is the percentage increase from January to February?

**Answer**

```
((100−80)/80)×100

=25%
```

---

## Q5

Which month shows a decrease compared to the previous month?

**Answer**

```
April
```
