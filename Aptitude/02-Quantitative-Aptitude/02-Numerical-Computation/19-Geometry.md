# Geometry

## Definition

**Geometry** is the branch of mathematics that studies **shapes, sizes, angles, distances, areas, and volumes**.

It deals with points, lines, angles, triangles, circles, polygons, and three-dimensional figures.

---

# Why Learn This?

Geometry is widely used in designing, measuring, and modeling physical objects.

Applications include:

- **Software Engineering** – Computer graphics, game development, CAD, and computer vision.
- **Architecture** – Building design and structural planning.
- **Civil Engineering** – Road, bridge, and building construction.
- **Manufacturing** – Product design and machining.
- **Robotics** – Navigation and object detection.
- **Geographic Information Systems (GIS)** – Mapping and satellite imaging.

# Basic Geometrical Terms


## Line


## Ray

```
A────────→
```

# Angles

An angle is formed when two rays meet at a common point.

Measured in

```
Degrees (°)
```

---

## Types of Angles

| Angle | Measure |
|--------|---------|
| Acute | Less than 90° |
| Right | 90° |
| Obtuse | Greater than 90° and less than 180° |
| Straight | 180° |
| Reflex | Greater than 180° and less than 360° |

- Alternate interior angles are equal.

# Solved Examples

## Example 1

Find the third angle of a triangle.

Angles

```
50°

60°
```

Solution

```
180−50−60

=70°
```

Answer

```
70°
```

---

## Example 2

Find the hypotenuse.

```
Base=6

Height=8
```

Solution

```
c²=6²+8²

=36+64

=100

c=10
```

Answer

```
10
```

---

## Example 3

Find the area of a circle.

```
r=7
```

Solution

```
π×7²

=49π

≈154
```

(using π = 22/7)

Answer

```
154 square units
```

---

## Example 4

Find the interior angle sum of a hexagon.

Solution

```
(6−2)×180

=720°
```

Answer

```
720°
```
