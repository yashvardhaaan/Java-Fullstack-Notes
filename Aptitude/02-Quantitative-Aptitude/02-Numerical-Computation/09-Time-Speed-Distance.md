# Time, Speed and Distance

## Definition

**Time, Speed, and Distance (TSD)** is a topic that describes the relationship between how fast an object moves, how far it travels, and how long it takes.

The three quantities are related by a simple formula.

```
Distance

=

Speed × Time
```

---

# Why Learn This?

Time, Speed, and Distance concepts are widely used in transportation, logistics, and technology.

Applications include:

- **Software Engineering** – Network latency, data transfer rates, and performance analysis.
- **Logistics** – Route planning and delivery optimization.
- **Transportation** – Travel time estimation and scheduling.
- **Robotics** – Robot movement and navigation.
- **GPS Systems** – Route optimization and ETA calculations.
- **Aviation & Railways** – Journey planning and scheduling.

# The Basic Formula Triangle

```
       Distance
      ──────────
      Speed × Time
```

From this,

```
Distance = Speed × Time
```

```
Speed = Distance ÷ Time
```

```
Time = Distance ÷ Speed
```

# Unit Conversion

## km/h to m/s

Formula

```
Multiply by

5/18
```

Example

```
72 km/h

↓

72×5/18

=20 m/s
```

---

## m/s to km/h

Formula

```
Multiply by

18/5
```

Example

```
15 m/s

↓

15×18/5

=54 km/h
```

# Average Speed

Formula

```
Average Speed

=

Total Distance
──────────────
Total Time
```

Example

```
Travel

```

Average Speed

```
120/2

=60 km/h
```

# Equal Distances

If equal distances are covered at speeds

```
a

and

b
```

Average Speed

```
2ab
─────
a+b
```

Example

```
60 km/h

and

40 km/h
```

Average Speed

```
2×60×40

────────

100

=48 km/h
```

---

# Relative Speed

## Moving in the Same Direction

Formula

```
Relative Speed

=

Difference of Speeds
```

Example

```
70 km/h

50 km/h
```

Relative Speed

```
70−50

=20 km/h
```

---

## Moving in Opposite Directions

Formula

```
Relative Speed

=

Sum of Speeds
```

Example

```
60 km/h

40 km/h
```

Relative Speed

```
60+40

=100 km/h
```

# GATE 80/20 Summary

✅ Memorize the three core formulas:
- **Distance = Speed × Time**
- **Speed = Distance ÷ Time**
- **Time = Distance ÷ Speed**

✅ Learn the unit conversions:
- **km/h → m/s = × 5/18**
- **m/s → km/h = × 18/5**

✅ Use **difference of speeds** for the same direction and **sum of speeds** for opposite directions.

✅ For equal distances, use the harmonic mean formula:

```
2ab
────
a+b
```

instead of taking the simple average.

✅ Most aptitude questions involve **basic TSD, trains, boats & streams, relative speed, and average speed**.
