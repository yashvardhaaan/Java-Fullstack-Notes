# Powers and Exponents

## Definition

An **Exponent (Power)** tells how many times a number (called the **Base**) is multiplied by itself.

General Form

```
aⁿ
```

Where

```
a = Base

n = Exponent (Power)
```

Example

```
2³

=2×2×2

=8
```

---

# Why Learn This?

Powers and Exponents are fundamental in mathematics and computer science.

Applications include:

- **Software Engineering** – Time complexity (O(2ⁿ)), memory calculations, and bit manipulation.
- **Data Science** – Exponential growth models and machine learning algorithms.
- **Finance** – Compound interest and investment growth.
- **Physics** – Scientific notation and large/small measurements.
- **Cybersecurity** – Cryptography and modular arithmetic.
- **Electronics** – Binary numbers and digital systems.

# Laws of Exponents

## 1. Product Rule

```
aᵐ × aⁿ

=aᵐ⁺ⁿ
```

Example

```
2³×2²

=2⁵

=32
```

---

## 2. Quotient Rule

```
aᵐ ÷ aⁿ

=aᵐ⁻ⁿ
```

Example

```
5⁶÷5²

=5⁴

=625
```

---

## 3. Power of a Power

```
(aᵐ)ⁿ

=aᵐⁿ
```

Example

```
(2³)²

=2⁶

=64
```

---

## 4. Power of a Product

```
(ab)ⁿ

=aⁿbⁿ
```

Example

```
(3×2)²

=3²×2²

=36
```

---

## 5. Power of a Quotient

```
(a/b)ⁿ

=aⁿ/bⁿ
```

Example

```
(4/5)²

=16/25
```

---

# Zero Exponent Rule

For any non-zero number,

```
a⁰

=1
```

Example

```
7⁰

=1
```

---

# Negative Exponent Rule

```
a⁻ⁿ

=1/aⁿ
```

Example

```
2⁻³

=1/2³

=1/8
```

---

# Exponent One Rule

```
a¹

=a
```

Example

```
15¹

=15
```

---

# Fractional Exponents

## Square Root

```
a¹ᐟ²

=√a
```

Example

```
25¹ᐟ²

=5
```

---

## Cube Root

```
a¹ᐟ³

=∛a
```

Example

```
27¹ᐟ³

=3
```

---

## General Rule

```
aᵐ⁄ⁿ

=ⁿ√(aᵐ)
```

Example

```
16³ᐟ²

=(√16)³

=4³

=64
```

---

# Scientific Notation

Large or very small numbers are written as

```
a×10ⁿ
```

Where

```
1≤a<10
```

Example

```
4,500,000

=4.5×10⁶
```

# Common Mistakes

### Mistake 1

Adding bases instead of exponents.

---

### Mistake 2

Using exponent rules for different bases.

Example

```
2²×3²

≠5⁴
```

---

### Mistake 3

Assuming

```
0⁰=1
```

It is **undefined** in elementary mathematics.

---

### Mistake 4

Forgetting that

```
a⁻ⁿ

=1/aⁿ
```

---

### Mistake 5

Ignoring brackets.

Example

```
(-2)²

=4

but

-2²

=-4
```

# GATE 80/20 Summary

✅ Memorize all **six exponent laws**.

✅ For the **same base**:
- Multiplication → **Add exponents**
- Division → **Subtract exponents**

✅ Remember:
- **a⁰ = 1** (for a ≠ 0)
- **a⁻ⁿ = 1/aⁿ**

✅ Fractional exponents represent **roots**.

✅ Most aptitude questions involve **simplification, negative exponents, fractional powers, and scientific notation**.
