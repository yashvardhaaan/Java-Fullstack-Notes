# Ratio and Proportion

## Definition

A **Ratio** is a comparison of two quantities of the same kind using division.

A **Proportion** is an equation stating that two ratios are equal.

Example

```
Ratio

6 : 3

=2 : 1
```

```
Proportion

2 : 4 = 3 : 6
```

or

```
2/4 = 3/6
```

Both ratios are equal, so they are in proportion.

---

# Why Learn This?

Ratio and Proportion are used whenever quantities need to be compared or distributed.

Applications include:

- **Software Engineering** – Aspect ratios, image scaling, load balancing, and resource allocation.
- **Data Science** – Comparing datasets, feature scaling, and statistical analysis.
- **Finance** – Profit sharing, investment allocation, and financial ratios.
- **Business Analytics** – Sales comparisons, market share analysis, and budgeting.
- **Engineering** – Gear ratios, scaling models, and design specifications.
- **Healthcare** – Medicine dosage calculations and solution preparation.

# Ratio

A ratio compares two quantities.

Formula

```
Ratio

=

First Quantity : Second Quantity
```

or

```
First Quantity / Second Quantity
```

Example

```
Boys = 12

Girls = 8
```

Ratio

```
12 : 8

=3 : 2
```

---

# Terms of a Ratio

For

```
a : b
```

- **a** → Antecedent
- **b** → Consequent

---

# Simplifying a Ratio

Divide both terms by their HCF.

Example

```
24 : 36

HCF = 12

24÷12 : 36÷12

=2 : 3
```

# Simple Ratio

Comparison of two quantities.

Example

```
8 : 12

=2 : 3
```

---

# Compound Ratio

Obtained by multiplying corresponding terms.

Example

```
2 : 3

and

4 : 5
```

Compound Ratio

```
(2×4):(3×5)

=8:15
```

---

# Duplicate Ratio

Square both terms.

Example

```
2 : 5

↓

4 : 25
```

---

# Triplicate Ratio

Cube both terms.

Example

```
2 : 3

↓

8 : 27
```

---

# Inverse Ratio

Exchange the terms.

Example

```
3 : 5

↓

5 : 3
```

---

# Proportion

Four quantities are said to be in proportion if

```
a : b = c : d
```

or

```
a/b = c/d
```

---

# Property of Proportion

For

```
a : b = c : d
```

```
a × d = b × c
```

This is called the **Cross Multiplication Rule**.

---

# Mean Proportional

If

```
a : x = x : b
```

Then

```
x² = ab
```

Therefore

```
x = √ab
```

Example

```
4 : x = x : 9

x² = 36

x = 6
```

---

# Third Proportional

If

```
a : b = b : x
```

Then

```
x = b² / a
```

Example

```
2 : 4 = 4 : x

x = 16/2

=8
```

---

# Fourth Proportional

If

```
a : b = c : x
```

Then

```
x = (b×c)/a
```

Example

```
2 : 5 = 4 : x

x=(5×4)/2

=10
```

---

# Direct Proportion

When one quantity increases, the other also increases.

```
Workers ↑

Work Done ↑
```

Formula

```
x₁/x₂ = y₁/y₂
```

Example

```
5 pens cost $50

10 pens cost $100
```

---

# Inverse Proportion

When one quantity increases, the other decreases.

```
Workers ↑

Time ↓
```

Formula

```
x₁×y₁ = x₂×y₂
```

Example

```
4 workers finish a job in 12 days.

8 workers finish it in

(4×12)/8

=6 days
```

# Shortcuts & Tricks

### 1. Always Simplify Ratios

```
18 : 24

↓

3 : 4
```

---

### 2. Remember

```
Ratio

↓

Comparison

Proportion

↓

Equality
```

---

### 3. Cross Multiplication Solves Most Questions

```
a×d=b×c
```

---

### 4. Keep Units the Same

Convert before comparing.

Example

```
2 m : 50 cm

↓

200 cm : 50 cm

↓

4 : 1
```

---

### 5. For Direct & Inverse Proportion

Identify whether both quantities move

- Together (Direct)
- Opposite (Inverse)

before applying formulas.

## Example 4

Eight workers complete a task in **15 days**.

How many days will **12 workers** take?

Solution

```

Days ↓

8×15 = 12×x

```

Answer

```
10 days
```
