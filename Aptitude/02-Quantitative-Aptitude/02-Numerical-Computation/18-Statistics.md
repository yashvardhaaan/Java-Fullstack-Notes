# Statistics

## Definition

**Statistics** is the branch of mathematics that deals with **collecting, organizing, analyzing, interpreting, and presenting data**.

It helps us make decisions based on data.

Example

```
Marks

70, 75, 80, 85, 90
```

Statistics helps answer questions like:

- What is the average mark?
- Which mark occurs most often?
- How spread out are the marks?

---

# Why Learn This?

Statistics is essential for analyzing and interpreting real-world data.

Applications include:

- **Data Science** – Data analysis, visualization, and machine learning.
- **Software Engineering** – Performance analysis and A/B testing.
- **Business Analytics** – Sales forecasting and customer behavior analysis.
- **Healthcare** – Clinical trials and disease analysis.
- **Finance** – Risk analysis and market prediction.
- **Government** – Census, surveys, and policy planning.

# Mean (Average)

Formula

```
Mean

=

Sum of Observations

──────────────────

Number of Observations
```

Example

```
Marks

50, 60, 70, 80, 90
```

```
Mean

=(50+60+70+80+90)/5

=350/5

=70
```

---

# Median

The **middle value** after arranging the data in ascending order.

### Odd Number of Observations

Formula

```
(n+1)/2 th term
```

Example

```
5, 8, 10, 15, 20
```

Median

```
10
```

---

### Even Number of Observations

Take the average of the two middle values.

Example

```
4, 8, 12, 16
```

Median

```
(8+12)/2

=10
```

---

# Mode

The value that occurs **most frequently**.

Example

```
3, 5, 5, 6, 7
```

Mode

```
5
```

---

# Relationship

```
Mean

Average Value

```

# Range

Measures the spread of data.

Formula

```
Range

=

Maximum Value

−

Minimum Value
```

Example

```
12, 18, 25, 30
```

```
Range

=30−12

=18
```

---

# Variance

Variance measures how far the observations are spread from the mean.

Population Variance

```
σ²

=

Σ(x−μ)²

────────

N
```

Sample Variance

```
s²

=

Σ(x−x̄)²

────────

n−1
```

---

# Standard Deviation

Standard deviation is the square root of variance.

Formula

```
σ

=

√Variance
```

A smaller standard deviation means the data is closer to the mean.

# GATE 80/20 Summary

✅ Memorize the three measures of central tendency:

- **Mean = Average**
- **Median = Middle Value**
- **Mode = Most Frequent Value**

✅ Always **sort the data** before finding the median.

✅ Remember:

- **Range = Maximum − Minimum**
- **Standard Deviation = √Variance**

✅ A **smaller standard deviation** means the data is more consistent.

✅ Most aptitude questions involve **mean, median, mode, range, and basic statistical interpretation**.
