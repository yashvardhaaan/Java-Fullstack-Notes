# Mixture and Alligation

## Definition

**Mixture** problems involve combining two or more ingredients with different costs, concentrations, or quantities to form a new mixture.

**Alligation** is a shortcut method used to find the ratio in which two ingredients should be mixed to obtain a desired average value.

---

# Why Learn This?

Mixture and Alligation are widely used in industries involving blending and concentration.

Applications include:

- **Chemical Engineering** – Mixing chemicals and solutions.
- **Food Industry** – Preparing beverages, spices, and dairy products.
- **Pharmaceuticals** – Medicine formulation and solution preparation.
- **Manufacturing** – Alloy production and material blending.
- **Petroleum Industry** – Fuel blending.
- **Data Science** – Weighted averaging and data combination models.

# What is Alligation?

Alligation is a shortcut method to determine the ratio in which two ingredients should be mixed.

---

# Alligation Rule

```
Higher Value
      │
      │ Difference
      ▼
 Desired Value
      ▲
      │ Difference
      │
Lower Value
```

Ratio

```
Higher : Lower

=

Difference with Lower

:

Difference with Higher
```

---

# Formula

If

```
Higher = H

Lower = L

Mean = M
```

Then

```
Ratio

=

(H−M)

:

(M−L)
```

# Shortcuts & Tricks

### 1. Use Alligation Instead of Equations

Most two-mixture problems become much faster using the alligation diagram.

---

### 2. Desired Value Must Lie Between the Two Values

```
Lower

<

Desired

<

Higher
```

Otherwise, no valid mixture exists.

---

### 3. Remember Cross Differences

```
Higher
   │
Difference
   ▼
Desired
   ▲
Difference
   │
Lower
```

The opposite differences form the ratio.

---

### 4. Replacement Questions

Memorize

```
((V−x)/V)^n
```

---

### 5. Keep Units Consistent

Use liters with liters, kilograms with kilograms, etc.
