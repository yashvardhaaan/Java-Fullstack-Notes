# Profit and Loss

## Definition

**Profit and Loss** is a topic that deals with the buying and selling of goods.

- If the **Selling Price (SP)** is greater than the **Cost Price (CP)**, there is a **Profit**.
- If the **Selling Price (SP)** is less than the **Cost Price (CP)**, there is a **Loss**.

---

# Why Learn This?

Profit and Loss is used in almost every business involving buying and selling.

Applications include:

- **Business & Retail** – Pricing products, calculating profits, and managing discounts.
- **Finance** – Investment returns and financial performance.
- **E-commerce** – Product pricing, promotional offers, and revenue analysis.
- **Manufacturing** – Production cost analysis and pricing decisions.
- **Accounting** – Preparing profit statements and financial reports.
- **Entrepreneurship** – Evaluating business performance and making pricing strategies.

# Basic Terminology

## Cost Price (CP)

The price at which an item is purchased.

Example

```
A laptop is purchased for

$800

CP = $800
```

---

## Selling Price (SP)

The price at which an item is sold.

Example

```
Laptop sold for

$950

SP = $950
```

---

## Profit

When

```
SP > CP
```

Formula

```
Profit

=

SP − CP
```

Example

```
CP = $500

SP = $650

Profit

=650−500

=$150
```

---

## Loss

When

```
SP < CP
```

Formula

```
Loss

=

CP − SP
```

Example

```
CP = $600

SP = $520

Loss

=600−520

=$80
```

---

# Profit Percentage

Formula

```
Profit %

=

(Profit/CP)×100
```

Example

```
CP = $400

SP = $500

Profit

=$100
```

```
Profit %

=(100/400)×100

=25%
```

---

# Loss Percentage

Formula

```
Loss %

=

(Loss/CP)×100
```

Example

```
CP = $500

SP = $450

Loss

=$50
```

```
Loss %

=(50/500)×100

=10%
```

---

# Selling Price Formula

## When Profit is Given

```
SP

=

CP×(100+Profit%)
/100
```

Example

```
CP = $600

Profit = 20%
```

```
SP

=(600×120)/100

=$720
```

---

## When Loss is Given

```
SP

=

CP×(100−Loss%)
/100
```

Example

```
CP = $800

Loss = 15%
```

```
SP

=(800×85)/100

=$680
```

## When Loss is Given

# Shortcuts & Tricks

### 1. Always Calculate Profit/Loss Using Cost Price

Profit % and Loss % are always calculated using **CP**, not SP.

---

### 2. Memorize Selling Price Formula

```
Profit

↓

CP×(100+P)/100
```

```
Loss

↓

CP×(100−L)/100
```

---

### 3. Successive Discounts

Do **not** add discounts directly.

Use

```
A+B−(AB/100)
```

---

### 4. Discount is Calculated on MP

Not on CP.

---

### 5. Profit and Discount Can Exist Together

A seller may offer a discount and still earn a profit if

```
SP > CP
```

# GATE 80/20 Summary

✅ Always calculate **profit and loss percentages using Cost Price (CP)**.

✅ Remember the three prices:
- **CP** → Buying Price
- **MP** → Printed Price
- **SP** → Selling Price

✅ Memorize the formulas for **SP**, **CP**, **Profit %**, and **Loss %**.

✅ Use the **successive discount formula** instead of adding discounts directly.

✅ Most aptitude questions involve **profit/loss percentage, marked price, discounts, and selling price calculations**.
