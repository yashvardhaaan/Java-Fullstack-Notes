# Averages

## Definition

An **Average** is a single value that represents the central or typical value of a group of numbers.

The most commonly used average is the **Arithmetic Mean**.

Formula

```
Average

=

Sum of Observations
───────────────────
Number of Observations
```

Example

```
10

20

30
```

Average

```
(10+20+30)/3

=20
```

---

# Why Learn This?

Averages are used whenever a large amount of data needs to be represented by a single meaningful value.

Applications include:

- **Software Engineering** – Average response time, CPU utilization, memory usage, and application performance.
- **Data Science** – Data analysis, statistical summaries, and feature engineering.
- **Finance** – Average stock prices, monthly expenses, and investment returns.
- **Business Analytics** – Average sales, customer ratings, and productivity metrics.
- **Healthcare** – Average heart rate, patient recovery time, and medical research.
- **Education** – Average marks, attendance, and performance evaluation.

# Arithmetic Mean

The Arithmetic Mean is the sum of all observations divided by the number of observations.

Formula

```
Average

=

Sum
────
Count
```

Example

```
Numbers

12

18

25

15
```

Solution

```
Sum

=12+18+25+15

=70

Average

=70/4

=17.5
```

# Weighted Average

Used when different observations have different importance (weights).

Formula

```
Weighted Average

=

Σ(Value × Weight)
─────────────────
ΣWeight
```

Example

| Subject | Marks | Credits |
|---------|------:|--------:|
| Math | 80 | 4 |
| Physics | 70 | 3 |

Solution

```
(80×4)+(70×3)

=320+210

=530
```

```
Total Credits

=7
```

Weighted Average

```
530/7

≈75.71
```

---

# Combined Average

Formula

```
Combined Average

=

(Total Sum₁ + Total Sum₂)
─────────────────────────
(Total Count₁ + Total Count₂)
```

Example

Group A

```
20 students

Average = 70
```

Group B

```
30 students

Average = 80
```

Solution

```
Total Marks

=(20×70)+(30×80)

=1400+2400

=3800
```

Combined Average

```
3800/50

=76
```

# Effect of Replacing a Value

Formula

```
Change in Average

=

(New Value−Old Value)
─────────────────────
Number of Observations
```

Example

```
One value changes

20 → 30

Count = 10
```

Increase in Average

```
(30−20)/10

=1
```

If one value increases by

Always calculate **total sums** first.

| Concept | Formula |
|----------|---------|
| Average | Sum ÷ Count |
| Sum | Average × Count |
| Count | Sum ÷ Average |
| Consecutive Numbers | (First + Last) ÷ 2 |
| Combined Average | Total Sum ÷ Total Count |
| Weighted Average | Σ(Value × Weight) ÷ ΣWeight |

---

# GATE 80/20 Summary

✅ Memorize the three core formulas:
- Average = Sum ÷ Count
- Sum = Average × Count
- Count = Sum ÷ Average

✅ For consecutive numbers, use:

```
(First + Last) ÷ 2
```

instead of adding every value.

✅ Never average averages directly unless all groups have the same size.

✅ For replacement questions, use the change-in-average shortcut:

```
(New Value − Old Value) ÷ Count
```

✅ Most aptitude questions involve **basic averages, combined averages, weighted averages, and missing values**.
