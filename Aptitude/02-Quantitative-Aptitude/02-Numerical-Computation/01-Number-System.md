# Number System

## Definition

The **Number System** is the foundation of mathematics. It deals with different types of numbers, their properties, operations, and relationships.

Almost every quantitative aptitude topic—including percentages, ratios, algebra, geometry, probability, and data interpretation—uses concepts from the Number System.

---

# Why Learn This?

Number Systems are used everywhere calculations are performed.

Applications include:

- **Software Engineering** – Binary numbers, hexadecimal, memory addressing, hashing, and algorithms.
- **Data Science** – Data preprocessing, numerical computation, and statistical analysis.
- **Finance** – Interest calculations, investments, taxation, and budgeting.
- **Engineering** – Measurements, signal processing, and system design.
- **Scientific Research** – Mathematical modeling and simulations.
- **Artificial Intelligence** – Optimization algorithms and numerical computations.

# Classification of Numbers

```
Number System
│
├── Natural Numbers (N)
├── Whole Numbers (W)
├── Integers (Z)
├── Rational Numbers (Q)
├── Irrational Numbers
├── Real Numbers (R)
└── Complex Numbers (C)
```

---

# 1. Natural Numbers (N)

Counting numbers starting from **1**.

```
1, 2, 3, 4, 5, ...
```

Properties

- Smallest = 1
- No negative numbers
- Infinite

---

# 2. Whole Numbers (W)

Natural numbers including zero.

```
0, 1, 2, 3, 4, ...
```

Properties

- Smallest = 0
- Infinite

---

# 3. Integers (Z)

Positive numbers, negative numbers, and zero.

```
..., -3, -2, -1, 0, 1, 2, 3, ...
```

---

# 4. Rational Numbers (Q)

Numbers that can be written as

```
p/q

where q ≠ 0
```

Examples

```
1/2

5/8

-7/9

4

0.25
```

---

# 5. Irrational Numbers

Numbers that **cannot** be written as a fraction.

Examples

```
√2

√3

π

e
```

Their decimal expansions are **non-terminating** and **non-repeating**.

---

# 6. Real Numbers (R)

All rational and irrational numbers together.

```
Real Numbers
│
├── Rational
└── Irrational
```

---

# 7. Complex Numbers

Numbers of the form

```
a + bi
```

where

```
i² = -1
```

Example

```
4 + 3i
```

---

# Even and Odd Numbers

## Even Numbers

Divisible by **2**.

```
2, 4, 6, 8, 10...
```

Properties

- Even + Even = Even
- Even × Even = Even
- Even × Odd = Even

---

## Odd Numbers

Not divisible by **2**.

```
1, 3, 5, 7, 9...
```

Properties

- Odd + Odd = Even
- Odd × Odd = Odd
- Even + Odd = Odd

---

# Prime Numbers

A **Prime Number** has exactly **two factors**:

- 1
- Itself

Examples

```
2

3

5

7

11

13
```

Important Facts

- 2 is the only even prime number.
- 1 is **not** a prime number.

---

# Composite Numbers

A **Composite Number** has **more than two factors**.

Examples

```
4

6

8

9

10

12
```

---

# Co-Prime Numbers

Two numbers are **co-prime** if their **HCF = 1**.

Examples

```
8 and 15

9 and 10

14 and 25
```

---

# Important Formulae

## Sum of First n Natural Numbers

```
n(n+1)/2
```

---

## Sum of First n Even Numbers

```
n(n+1)
```

---

## Sum of First n Odd Numbers

```
n²
```

---

## Number of Integers Between a and b

```
b − a − 1
```

(when **a < b** and both are integers)

---

# Divisibility Tests

| Number | Rule |
|---------|------|
| 2 | Last digit is even |
| 3 | Sum of digits divisible by 3 |
| 4 | Last two digits divisible by 4 |
| 5 | Last digit is 0 or 5 |
| 6 | Divisible by 2 and 3 |
| 8 | Last three digits divisible by 8 |
| 9 | Sum of digits divisible by 9 |
| 10 | Last digit is 0 |
| 11 | Difference of alternating digit sums is divisible by 11 |
