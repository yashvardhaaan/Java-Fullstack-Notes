# Percentages

## Definition

A **Percentage** is a way of expressing a number as a fraction of **100**.

The symbol used for percentage is

```
%
```

Example

```
25%

means

25/100

=0.25
```

Percentages are used to compare quantities, calculate increases or decreases, discounts, profits, taxes, interest, and much more.

---

# Why Learn This?

Percentages are one of the most widely used mathematical concepts in everyday life.

Applications include:

- **Software Engineering** – CPU utilization, memory usage, code coverage, and progress indicators.
- **Data Science** – Accuracy, precision, recall, error rates, and statistical analysis.
- **Finance** – Interest rates, taxes, discounts, investments, and inflation.
- **Business Analytics** – Sales growth, profit margins, customer retention, and market share.
- **Healthcare** – Recovery rates, medicine concentration, and clinical statistics.
- **Education** – Grades, attendance, and performance analysis.

# What is Percentage?

```
Percentage

=

Example

```

Total = 90

Percentage

=(72/90)×100

=80%

# Percentage Increase

Formula

```
((New−Old)/Old)×100
```

Example

```
Old Price

=$80

New Price

=$100
```

Increase

```
((100−80)/80)×100

=25%
```

---

# Percentage Decrease

Formula

```
((Old−New)/Old)×100
```

Example

```
Old Price

=$100

New Price

=$75
```

Decrease

```
((100−75)/100)×100

=25%
```

---

# Successive Percentage Change

Formula

```
A+B+(AB/100)
```

Where

```
A

First %

B

Second %
```

Example

```
Increase by 20%

Then

Increase by 10%
```

Net Change

```
20+10+(20×10/100)

=32%
```

# GATE 80/20 Summary

✅ Memorize common fraction-percentage conversions (1/2, 1/3, 1/4, 1/5, 3/4, etc.).

✅ Always use the **original value** as the base when calculating percentage increase or decrease.

✅ Remember the formula for **successive percentage changes**:

```
A + B + (AB ÷ 100)
```

✅ Convert percentages into fractions whenever possible for faster calculations.

✅ Most aptitude questions involve **percentage calculation, increase/decrease, successive changes, and ratio conversions**.
