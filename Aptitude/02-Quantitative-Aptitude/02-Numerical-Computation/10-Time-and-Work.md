# Time and Work

## Definition

**Time and Work** deals with the relationship between the amount of work done, the number of workers, and the time taken to complete the work.

The basic principle is:

```
More Workers

↓

Less Time
```

```
Fewer Workers

↓

More Time
```

Time and Work is based on the concept of **work rate (efficiency).**

---

# Why Learn This?

Time and Work concepts are widely used for planning and optimizing tasks.

Applications include:

- **Software Engineering** – Sprint planning, task estimation, and resource allocation.
- **Project Management** – Workforce planning and project scheduling.
- **Manufacturing** – Production planning and assembly line optimization.
- **Construction** – Labor estimation and project completion.
- **Business Operations** – Productivity measurement and workforce management.
- **Healthcare** – Staff scheduling and hospital resource planning.

# Basic Formula

```
Work

=

Efficiency × Time
```

From this,

```
Efficiency

=

Work ÷ Time
```

```
Time

=

Work ÷ Efficiency
```

---

# Total Work Method

For aptitude questions, assume

```
Total Work

=

LCM of all given times
```

This avoids fractions and simplifies calculations.

Example

If

```
A = 12 days

B = 18 days
```

Assume

```
Total Work

=LCM(12,18)

=36 units
```

Then

```
A's Efficiency

=36/12

=3 units/day
```

```
B's Efficiency

=36/18

=2 units/day
```

---

# Efficiency

Efficiency means the amount of work completed in one unit of time.

Formula

```
Efficiency

=

1
──
Time
```

Example

```
A completes work in

10 days
```

Efficiency

```
1/10
```

---

# Combined Work

If two people work together,

```
Combined Efficiency

=

Efficiency₁ + Efficiency₂
```

Formula

```
1/T

=

1/A + 1/B
```

Where

```
A

=

Days taken by Person A
```

```
B

=

Days taken by Person B
```

---

# Example

```
A

=12 days

B

=18 days
```

Solution

```
1/T

=1/12+1/18

=(3+2)/36

=5/36
```

Therefore

```
T

=36/5

=7.2 days
```

Remaining Work

Example

Remaining

Solution

10×15

# Pipes and Cisterns

Pipes filling a tank behave like workers doing work.

```
Filling Pipe

↓

Positive Work
```

```
Emptying Pipe

↓

Negative Work
```

Formula

```
Net Rate

=

Fill Rate−Empty Rate
```

---

# Efficiency Ratio

Efficiency is inversely proportional to time.

If

```
A:B

=2:3
```

Then

```
Time

=3:2
```

---

# Wages

If wages depend only on work,

```
Wages

∝

Work Done
```

If work is proportional to efficiency,

```
Wages

∝

Efficiency
```
