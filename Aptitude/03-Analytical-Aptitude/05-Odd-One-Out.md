# Odd One Out

## Definition

**Odd One Out** is a reasoning topic where you are given a group of words, numbers, letters, symbols, or figures. Your task is to identify the item that **does not follow the common pattern or relationship** shared by the others.

General Structure

```
Given Items

↓

Find Common Pattern

↓

Identify Different Item

↓

Odd One Out
```

Example

```
2, 4, 6, 9

Answer

9
```

Reason

```
2, 4, 6

↓

Even Numbers

9

↓

Odd Number
```

---

# Why Learn This?

Odd One Out questions help develop classification and pattern recognition skills.

Applications include:

- **Artificial Intelligence** – Object classification and anomaly detection.
- **Software Engineering** – Identifying unexpected behavior and debugging.
- **Data Science** – Outlier detection in datasets.
- **Cybersecurity** – Detecting unusual network activity.
- **Healthcare** – Identifying abnormal medical readings.
- **Business Analytics** – Spotting unusual trends or transactions.

Find the hidden relationship.

Example

```

```

Pattern

```

```

Odd One

```

```

---

## Similarity

Three or more items usually share a common feature.

The remaining item is the answer.

# Rules for Solving

## Rule 1

Identify what is common among most items.

---

## Rule 2

Do not focus on one item first.

Compare all items together.

---

## Rule 3

Check:

- Numbers
- Letters
- Categories
- Functions
- Relationships

---

## Rule 4

If numbers are given, check:

```
+

-

×

÷

Squares

Cubes

Prime Numbers
```

---

## Rule 5

The odd item usually violates **one major pattern**.

---

# Solving Strategy

```
Read All Items
       │
       ▼
Find Common Property
       │
       ▼
Compare Every Item
       │
       ▼
Identify Different One
       │
       ▼
Answer
```

# Shortcuts & Tricks

### 1. Group Similar Items

If three items naturally belong together,

the fourth is usually the answer.

---

### 2. Check Categories

Example

```
Dog

Cat

Cow

Table
```

Answer

```
Table
```

---

### 3. For Numbers

Always check

- Addition
- Multiplication
- Prime Numbers
- Squares
- Cubes

---

### 4. For Letters

Convert to alphabet positions.

Example

```
A = 1

C = 3

E = 5
```

---

### 5. Look for Hidden Relationships

Example

```
Pilot

Airplane

Driver

Teacher
```

Three items relate to transportation.

# GATE 80/20 Summary

✅ First identify the **common pattern** shared by most items.

✅ Check in this order:

1. Category
2. Mathematical Pattern
3. Alphabet Pattern
4. Relationship
5. Function

✅ For number-based questions, always check:

- Addition/Subtraction
- Multiplication/Division
- Prime Numbers
- Squares
- Cubes

✅ For letter-based questions:

- Convert letters into alphabet positions.
- Look for equal forward/backward shifts.

✅ Most Odd One Out questions can be solved by finding **one strong common property** shared by all but one item.
