# Directions

## Definition

**Directions** is a logical reasoning topic where you determine a person's **final direction, position, or shortest distance** after a series of movements.

These questions involve:

- North, South, East, West
- Left and Right Turns
- Distance Travelled
- Final Direction
- Shortest Distance

General Structure

```
Starting Direction

↓

Series of Movements

↓

Track Position

↓

Find Direction/Distance
```

Example

```
A person walks 5 km North,

then turns Right and walks 3 km.

Final Direction?

Answer

East
```

---

# Why Learn This?

Direction reasoning is useful wherever navigation and spatial reasoning are required.

Applications include:

- **Software Engineering** – Robot navigation and pathfinding algorithms.
- **Artificial Intelligence** – Autonomous vehicles and route planning.
- **Geographic Information Systems (GIS)** – Map-based navigation.
- **Logistics** – Delivery route optimization.
- **Gaming** – Character movement and map navigation.
- **Robotics** – Motion planning and obstacle avoidance.

## Final Position

Determine the ending location after all movements.

---

## Shortest Distance

Find the direct distance between the start and end points.

Usually solved using the **Pythagorean Theorem**.

Formula

```
Distance² = Horizontal² + Vertical²
```

or

```
d = √(x² + y²)
```

Example

```
3 km East

4 km North

↓

Distance

= √(3² + 4²)

= 5 km
```

---

## Direction Between Two Points

Determine the direction of one point relative to another.

# Coordinate Method

Assign coordinates:

```
North  = +Y

South  = -Y

East   = +X

West   = -X
```

Example

```
Start

(0,0)

↓

East 5

(5,0)

↓

North 4

(5,4)
```

---

# Rules for Solving

## Rule 1

Always draw the path.

---

## Rule 2

Track the current facing direction after every turn.

---

## Rule 3

Do not assume the person always faces North.

---

## Rule 4

Use coordinates for long questions.

---

## Rule 5

Use the Pythagorean Theorem for shortest-distance questions.

---

# Solving Strategy

```
Read Starting Direction
          │
          ▼
Draw Path
          │
          ▼
Update Direction
After Every Turn
          │
          ▼
Track Final Position
          │
          ▼
Find Direction
or Distance
```

# GATE 80/20 Summary

✅ Draw the path instead of solving mentally.

✅ Remember:

- **Right = Clockwise**
- **Left = Anti-clockwise**

✅ Track the current direction after **every** turn.

✅ For shortest-distance questions:

```
d = √(x² + y²)
```

✅ Use coordinate axes for long movement problems:

- North = +Y
- South = -Y
- East = +X
- West = -X

✅ Most Direction questions are solved correctly by **drawing a simple diagram** and updating the facing direction step by step.
