# Analogy

## Definition

An **Analogy** is a comparison between two pairs of words, numbers, figures, or concepts based on a **similar relationship**.

The goal is to identify the **same relationship** between the second pair as exists in the first pair.

General Form

```
A : B :: C : ?

Read as

A is related to B

in the same way that

C is related to ?
```

Example

```
Bird : Nest :: Bee : ?

Answer

Hive
```

Relationship

```
Bird lives in Nest

Bee lives in Hive
```

---

# Why Learn This?

Analogy helps identify relationships, patterns, and associations that are useful in many real-world domains.

Applications include:

- **Artificial Intelligence** – Knowledge representation and semantic reasoning.
- **Software Engineering** – Object relationships and system modeling.
- **Data Science** – Pattern recognition and feature similarity.
- **Education** – Concept learning through comparisons.
- **Healthcare** – Symptom and disease association.
- **Business Analytics** – Identifying similar customer behaviors and trends.

# Core Concepts

## Relationship

Every analogy is based on a relationship.

Example

```
Teacher : School

```

Relationship

```
Person

↓

```

---

## Pair Matching

Find the same relationship in another pair.

Example

```
Pencil : Write

Knife : Cut
```

Relationship

```
Tool

↓

Purpose
```

# Types of Analogies

## 1. Synonym Analogy

Words having similar meanings.

Example

```
Happy : Joyful

Big : Large
```

---

## 2. Antonym Analogy

Words having opposite meanings.

Example

```
Hot : Cold

Rich : Poor
```

---

## 3. Part to Whole

Example

```
Wheel : Car

Page : Book
```

---

## 4. Whole to Part

Example

```
Forest : Tree

Body : Heart
```

---

## 5. Function Analogy

Example

```
Pen : Write

Knife : Cut
```

---

## 6. Worker and Workplace

Example

```
Teacher : School

Judge : Court
```

---

## 7. Worker and Tool

Example

```
Carpenter : Hammer

Doctor : Stethoscope
```

---

## 8. Cause and Effect

Example

```
Fire : Smoke

Rain : Flood
```

---

## 9. Degree Analogy

Example

```
Warm : Hot

Cold : Freezing
```

---

## 10. Number Analogy

Example

```
2 : 4

3 : 9
```

Relationship

```
Square

2² = 4

3² = 9
```

---

## 11. Letter Analogy

Example

```
ABC : BCD

PQR : ?
```

Answer

```
QRS
```

Every letter shifts by one.

---

## 12. Figure Analogy

Two figures have the same transformation.

Example

```
Square

↓

Rotated Square
```

Find the figure with the same transformation.

# Rules for Solving

## Rule 1

First identify the relationship in the first pair.

---

## Rule 2

Apply exactly the same relationship to the second pair.

---

## Rule 3

Do not compare words directly.

Compare the relationship.

---

## Rule 4

Check every option before choosing.

---

## Rule 5

If more than one relationship exists, choose the strongest logical relationship.

---

# Solving Strategy

```
Read First Pair
        │
        ▼
Identify Relationship
        │
        ▼
Read Second Pair
        │
        ▼
Apply Same Relationship
        │
        ▼
Choose Best Match
```

### 2. Ignore Word Meaning Initially

### 3. Eliminate Wrong Relationships

- Function
- Synonym
- Antonym

- Worker–Tool

### 5. For Letter Analogies

- Forward shift

# GATE 80/20 Summary

✅ First identify the **relationship**, not the words.

✅ Memorize the most common analogy types:

- Synonym
- Antonym
- Part–Whole
- Whole–Part
- Function
- Worker–Tool
- Worker–Workplace
- Cause–Effect
- Number
- Letter

✅ For number analogies, check:

- Addition/Subtraction
- Multiplication/Division
- Square/Cube
- Prime numbers

✅ For letter analogies, check:

- Alphabet positions
- Forward/Backward shifts
- Wrapping from Z → A

✅ Eliminate options that match the words but **not** the relationship.
