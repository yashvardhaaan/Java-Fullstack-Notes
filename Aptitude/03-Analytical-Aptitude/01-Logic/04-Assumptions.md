# Assumptions

## Definition

An **Assumption** is an **unstated belief or fact** that is taken for granted for a statement or argument to make sense.

It is **not directly stated**, but it is **implicitly accepted** by the speaker or writer.

General Structure

```
Statement

↓

Hidden Belief

↓

Assumption
```

Example

```
Statement

"Buy this water purifier to keep your family healthy."

Hidden Belief

↓

Impure water can affect health.

Assumption

↓

The purifier improves water quality.
```

# Why Learn This?

Assumption-based reasoning is widely used in decision-making and communication.

Applications include:

- **Software Engineering** – Requirement analysis and system design.
- **Artificial Intelligence** – Knowledge representation and inference.
- **Business** – Marketing campaigns and customer behavior analysis.
- **Law** – Legal arguments and case analysis.
- **Healthcare** – Medical decision support.
- **Management** – Strategic planning and risk assessment.

# Core Concepts

## Statement

A sentence containing information.

Example

```
Wear a helmet while riding a motorcycle.
```

---

## Assumption

The hidden idea required for the statement to be meaningful.

Example

```
Helmets improve safety.
```

---

## Important Rule

An assumption is **not directly written**.

It is something the speaker **expects the listener to believe**.

---

# Characteristics of Assumptions

An assumption is:

- Implicit
- Necessary
- Unstated
- Reasonable
- Supports the statement

It is **not**:

- A conclusion
- A fact proved by evidence
- An unrelated opinion

---

# Types of Assumptions

## Necessary Assumption

Without it, the statement becomes meaningless.

Example

```
Use sunscreen before going outside.

Assumption

↓

Sunlight can damage the skin.
```

---

## Practical Assumption

Based on common practical knowledge.

Example

```
Take an umbrella.

Assumption

↓

It may rain.
```

---

## Value-Based Assumption

Depends on beliefs or preferences.

Example

```
Exercise every day.

Assumption

↓

Good health is desirable.
```

---

# How to Identify Assumptions

Ask yourself:

```
What must be true

for this statement

to make sense?
```

If removing that idea makes the statement weak or meaningless,

it is likely an assumption.

---

# Difference Between Assumption and Conclusion

| Assumption | Conclusion |
|------------|------------|
| Hidden | Explicitly inferred |
| Before the argument | After the argument |
| Taken for granted | Derived logically |
| Supports the statement | Result of the statement |

---

# Rules for Solving

## Rule 1

Read the statement carefully.

---

## Rule 2

Identify the purpose of the statement.

---

## Rule 3

Look for the hidden belief.

---

## Rule 4

Do not introduce unrelated information.

---

## Rule 5

An assumption is usually **necessary**, not merely possible.

---

# Solving Strategy

```
Read Statement
      │
      ▼
Identify Purpose
      │
      ▼
Ask

"What must be true?"
      │
      ▼
Find Hidden Belief
      │
      ▼
Check Necessity
      │
      ▼
Answer
```

---

# Shortcuts & Tricks

### 1. Use the Question

```
What is taken for granted?
```

---

### 2. Ignore Extreme Ideas

Words like

```
Always

Never

Everyone

Nobody
```

are rarely assumptions unless directly required.

---

### 3. Remove the Assumption

Ask

```
Does the statement still make sense?
```

If **No**,

it is probably an assumption.

---

### 4. Focus on Necessity

Necessary assumption

✔

Useful but unnecessary information

✖

---

### 5. Do Not Use Outside Knowledge

Only analyze the given statement.

# Common Mistakes

---

### Mistake 3

---

# GATE 80/20 Summary

✅ An **assumption is always hidden**.

✅ Ask yourself:

```
"What must be true

for this statement

to make sense?"
```

✅ Remember:

- Assumption → **Supports** the statement.
- Conclusion → **Results from** the statement.

✅ Eliminate options that are:

- Too extreme
- Unrelated
- Already stated
- Personal opinions

✅ Most analytical aptitude questions test your ability to identify **necessary hidden assumptions**, especially in advertisements, instructions, business statements, and everyday scenarios.
