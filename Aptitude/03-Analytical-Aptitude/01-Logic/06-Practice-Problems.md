# Practice Problems

## Instructions

For each question:

1. Read the given statements carefully.
2. Do **not** use outside knowledge.
3. Apply logical reasoning only.
4. Choose the correct answer.
5. Check the explanation after attempting the question.

# Level 1 — Easy

## Question 1

### Statements

```
All programmers are logical thinkers.

Rahul is a programmer.
```

### Conclusion

```
Rahul is a logical thinker.
```

**Options**

A. Follows

B. Does Not Follow

**Answer**

```
A. Follows
```

**Explanation**

```
Programmer

↓

Logical Thinker

Rahul is a programmer.

↓

Rahul is a logical thinker.
```

# Level 2 — Moderate

## Question 6

### Statements

```
All doctors are educated.

Some educated people are writers.
```

### Conclusions

1.

```
Some doctors are writers.
```

2.

```
All doctors are educated.
```

**Answer**

```
1. Does Not Follow

2. Follows
```

**Explanation**

The first conclusion cannot be guaranteed because there is no direct relationship between doctors and writers.

## Deduction

```
↓

↓

Certain Conclusion
```

```
Specific

↓

General

↓

```

## Statements & Conclusions

- Accept statements as true.
- Do not use outside knowledge.
- Evaluate each conclusion independently.

# GATE 80/20 Summary

✅ Memorize these five reasoning topics:

- Deduction
- Induction
- Statements & Conclusions
- Assumptions
- Cause & Effect

✅ Always identify keywords:

- **All**
- **Some**
- **No**
- **Only**
- **If...Then**

✅ Draw Venn diagrams for set-based questions.

✅ Never use outside knowledge.

✅ Practice identifying hidden assumptions and distinguishing **correlation from causation**.
