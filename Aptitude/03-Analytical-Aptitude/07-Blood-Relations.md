# Blood Relations

## Definition

**Blood Relations** is a logical reasoning topic in which you determine the relationship between two or more people based on the information given.

These questions test your ability to understand **family relationships** and identify connections such as father, mother, brother, sister, uncle, aunt, grandfather, and cousin.

General Structure

```
Given Family Information

↓

Identify Relationships

↓

Draw Family Tree

↓

Find Required Relation
```

Example

```
A is the father of B.

B is the mother of C.

↓

A is the grandfather of C.
```

---

# Why Learn This?

Blood relation reasoning helps analyze hierarchical and relationship-based information.

Applications include:

- **Software Engineering** – Tree structures and hierarchical data modeling.
- **Artificial Intelligence** – Knowledge graphs and relationship inference.
- **Database Design** – Entity relationship modeling.
- **Genealogy** – Family tree analysis.
- **Healthcare** – Understanding hereditary diseases.
- **Law** – Family inheritance and legal relationships.

# Common Relationship Terms

| Relation | Meaning |
|----------|---------|
| Father | Male parent |
| Mother | Female parent |
| Son | Male child |
| Daughter | Female child |
| Brother | Male sibling |
| Sister | Female sibling |
| Uncle | Father's/Mother's brother |
| Aunt | Father's/Mother's sister |
| Nephew | Brother's/Sister's son |
| Niece | Brother's/Sister's daughter |
| Cousin | Uncle's or Aunt's child |
| Grandfather | Father's/Mother's father |
| Grandmother | Father's/Mother's mother |

# Types of Blood Relation Questions

## Direct Statements

Example

```
A is the father of B.

B is the brother of C.

Find A's relation to C.
```

Answer

```
Father
```

---

## Chain Relationship

Example

```
A is the mother of B.

B is the father of C.

C is the sister of D.
```

Find

```
A's relation to D.
```

Answer

```
Grandmother
```

---

## Coded Relations

Example

```
+

=

-

=
```

Decode the relationship using the given symbols.

# Rules for Solving

## Rule 1

Identify the gender whenever possible.

---

## Rule 2

Move generation by generation.

---

## Rule 3

Draw a family tree for long questions.

---

## Rule 4

Do not assume relationships that are not given.

---

## Rule 5

Read every statement carefully before drawing conclusions.

# GATE 80/20 Summary

✅ Always identify **gender** first.

✅ Draw a **family tree** for questions involving more than three people.

✅ Solve relationships one statement at a time.

✅ Remember these common shortcuts:

- Father's brother → Uncle
- Mother's sister → Aunt
- Brother's son → Nephew
- Sister's daughter → Niece
- Uncle's child → Cousin

✅ If gender is **not specified**, do **not** assume it.

✅ Most Blood Relation questions become straightforward once the family tree is drawn correctly.
