# Coding-Decoding

## Definition

**Coding-Decoding** is a logical reasoning topic in which a word, letter, number, or symbol is represented using a particular rule (called a **code**). Your task is to identify the rule and use it to **encode** or **decode** similar information.

General Structure

```
Given Code

↓

Identify Rule

↓

Apply Rule

↓

Find Answer
```

Example

```
CAT → DBU

Rule

Each letter shifts +1.

C → D

A → B

T → U
```

---

# Why Learn This?

Coding-Decoding develops pattern recognition and logical analysis skills.

Applications include:

- **Cybersecurity** – Encryption and secure communication.
- **Software Engineering** – Data encoding and transformation.
- **Artificial Intelligence** – Pattern recognition.
- **Data Compression** – Symbol encoding techniques.
- **Communication Systems** – Error detection and coding.
- **Cryptography** – Secret message encoding.

# Types of Coding-Decoding

## 1. Letter Shift Coding

Each letter moves by a fixed number.

Example

```
CAT

↓

DBU

(+1)
```

---

## 2. Reverse Alphabet Coding

Replace letters using opposite alphabet positions.

```
A ↔ Z

B ↔ Y

C ↔ X

D ↔ W
```

Example

```
CAT

↓

XZG
```

---

## 3. Reverse Word Coding

Reverse the order of letters.

Example

```
TRAIN

↓

NIART
```

---

## 4. Number Coding

Each letter is replaced by its alphabet position.

Example

```
CAT

↓

3 1 20
```

---

## 5. Mixed Coding

Uses multiple operations.

Example

```
DOG

↓

EPH

↓

5 16 8
```

---

## 6. Symbol Coding

Letters or numbers are replaced with symbols.

Example

```
A → @

B → #

C → &
```

## Rule 1

Look for simple letter shifts.

```
+1

+2

-1

-2
```

---

## Rule 2

Convert letters into alphabet positions.

Example

```
A = 1

B = 2

C = 3
```

---

## Rule 3

Check whether the word is reversed.

---

## Rule 4

Check for alternate shifts.

Example

```
+1

+2

+1

+2
```

---

## Rule 5

If letters become numbers,

check alphabet positions first.

# GATE 80/20 Summary

✅ Check coding rules in this order:

1. Letter Shift (+1, +2, -1)
2. Alphabet Position
3. Reverse Word
4. Opposite Alphabet
5. Alternate Shifts
6. Symbol Replacement

✅ Memorize:

- Alphabet positions (A = 1 to Z = 26)
- Opposite alphabet pairs:
  - A ↔ Z
  - B ↔ Y
  - C ↔ X
  - D ↔ W

✅ Always compare each letter individually before assuming a complex rule.

✅ Most Coding-Decoding questions involve **simple shifts, reversals, or alphabet position mapping**, so checking these first saves time.
