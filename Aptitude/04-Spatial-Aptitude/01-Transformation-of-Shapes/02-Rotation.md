# Rotation

## Definition

**Rotation** is a geometric transformation in which a figure is turned around a fixed point called the **center of rotation** by a specified angle and direction.

The figure's **shape, size, angles, and distances remain unchanged**. Only its orientation changes.

General Structure

```
Original Figure

        ↓
 Rotate About a Fixed Point

        ↓

Rotated Figure
```

Example

```
Before

   ▲

Rotate 90° Clockwise

After

▶
```

---

# Why Learn This?

Rotation is an essential concept in many real-world applications.

Applications include:

- Computer Graphics – Rotating images and objects.
- Robotics – Controlling robotic arm movement.
- Game Development – Character and camera rotation.
- CAD Software – Rotating engineering models.
- Satellite Navigation – Orientation of spacecraft.
- Augmented Reality (AR) – Rotating virtual objects.

# Important Formulae

## 90° Counterclockwise (About Origin)

```
(x, y)

↓

(-y, x)
```

---

## 90° Clockwise (About Origin)

```
(x, y)

↓

(y, -x)
```

---

## 180° Rotation

```
(x, y)

↓

(-x, -y)
```

---

## 270° Counterclockwise

```
(x, y)

↓

(y, -x)
```

---

## 360° Rotation

```
(x, y)

↓

(x, y)
```

(No Change)

# Rules / Properties

### Property 1

Rotation preserves

- Length
- Angles
- Area
- Shape

---

### Property 2

Orientation changes.

---

### Property 3

The distance from the center remains constant.

---

### Property 4

Every point rotates through the same angle.

---

### Property 5

A full rotation equals

```
360°
```

# GATE 80/20 Summary

✅ Rotation turns a figure about a **fixed center**.

✅ Memorize these coordinate transformations:

- 90° Clockwise → `(y, -x)`
- 90° Counterclockwise → `(-y, x)`
- 180° → `(-x, -y)`

✅ Rotation preserves:

- Shape
- Size
- Angles
- Area
- Distances

✅ Rotation changes the **orientation** of the figure but not its dimensions.
