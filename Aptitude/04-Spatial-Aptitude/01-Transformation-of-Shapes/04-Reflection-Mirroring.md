# Reflection (Mirroring)

## Definition

**Reflection**, also called **Mirroring**, is a geometric transformation in which a figure is **flipped** over a line called the **line of reflection (mirror line)**.

The reflected figure is the **same size and shape** as the original but appears on the **opposite side** of the mirror line.

General Structure

```
Original Figure

        │ Mirror Line
        │

        ↓

Reflected Figure
```

Example

```
Original        Mirror        Reflection

   ▲               │               ▲
                   │
```

---

# Why Learn This?

Reflection is widely used in visualization and design.

Applications include:

- Computer Graphics – Image flipping.
- Robotics – Vision systems.
- Architecture – Symmetrical building designs.
- Animation – Character mirroring.
- Medical Imaging – Comparing left and right body structures.
- Manufacturing – Designing symmetrical machine parts.

# Core Concepts

## Mirror Line

Reflection always occurs about a mirror line.

Common mirror lines

```
x-axis

y-axis

y = x

y = -x
```

---

## Equal Distance Property

Each reflected point is the **same distance** from the mirror line as the original point.

```
Original

     ●

------ Mirror ------

     ●

Reflection
```

---

## Congruence

Reflection preserves

- Shape
- Size
- Length
- Angles

---

## Orientation

Reflection reverses orientation.

Example

```
Original

ABC

↓

Reflection

CBA
```

# Rules / Properties

### Property 1

Reflection preserves

- Shape
- Size
- Area
- Angles

---

### Property 2

Orientation is reversed.

---

### Property 3

The mirror line is the perpendicular bisector between a point and its reflection.

---

### Property 4

Corresponding sides remain equal.

---

### Property 5

Every reflected point remains the same distance from the mirror line.

# Shortcuts & Tricks

### 1. Reflection About X-axis

Only the **y-coordinate** changes sign.

```
(x,y)

↓

(x,-y)
```

---

### 2. Reflection About Y-axis

Only the **x-coordinate** changes sign.

```
(x,y)

↓

(-x,y)
```

---

### 3. Reflection About Origin

Both coordinates change sign.

```
(x,y)

↓

(-x,-y)
```

---

### 4. Reflection About y = x

Swap coordinates.

```
(x,y)

↓

(y,x)
```

---

### 5. Reflection Never Changes Shape

Only position and orientation change.

# Common Mistakes

### Mistake 1

Changing both coordinates for an x-axis reflection.

Only **y** changes sign.

---

### Mistake 2

Changing the size of the figure.

Reflection never changes size.

---

### Mistake 3

Confusing reflection with rotation.

---

### Mistake 4

Forgetting to swap coordinates for

```
y = x
```

---

### Mistake 5

Ignoring negative signs.

# GATE 80/20 Summary

✅ Reflection flips a figure across a **mirror line**.

✅ Memorize these formulas:

- x-axis → `(x, -y)`
- y-axis → `(-x, y)`
- Origin → `(-x, -y)`
- `y = x` → `(y, x)`
- `y = -x` → `(-y, -x)`

✅ Reflection preserves:

- Shape
- Size
- Area
- Angles

✅ Reflection changes the **orientation** of the figure while keeping every reflected point the **same perpendicular distance** from the mirror line.
