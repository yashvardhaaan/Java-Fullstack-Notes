# Translation

## Definition

**Translation** is a geometric transformation in which a figure is moved from one position to another **without changing its shape, size, orientation, or angles**.

Every point of the figure moves the **same distance** in the **same direction**.

General Structure

```
Original Figure

        ↓
 Move by a Fixed Distance
 in a Fixed Direction

        ↓

Translated Figure
```

Example

```
Before

   ■

Move 3 units right

After

         ■
```

---

# Why Learn This?

Translation is widely used in many real-world applications.

Applications include:

- Computer Graphics – Moving objects on a screen.
- Game Development – Character and camera movement.
- Robotics – Robot path planning.
- GPS Navigation – Updating positions on digital maps.
- Animation – Smooth movement of objects.
- CAD Software – Positioning engineering drawings.

# Core Concepts

## Translation Vector

A translation is represented using a vector.

Example

```
(3, 2)

Means

3 units Right

2 units Up
```

---

## Position Changes

Original Point

```
(x, y)
```

Translated Point

```
(x + a, y + b)
```

where

```
a = Horizontal Shift

b = Vertical Shift
```

---

## Shape Remains Same

Translation never changes

- Length
- Area
- Angles
- Shape
- Orientation

Only the **position** changes.

---

## Direction of Movement

```
Right

(+x)

Left

(-x)

Up

(+y)

Down

(-y)
```

---

# Important Formulae

## Translation Formula

```
(x, y)

↓

(x + a, y + b)
```

---

## Horizontal Translation

```
(x, y)

↓

(x + a, y)
```

---

## Vertical Translation

```
(x, y)

↓

(x, y + b)
```

---

## Translation Vector

```
T(a, b)
```

Example

```
T(4, -2)

↓

4 Right

2 Down
```

---

# Rules / Properties

### Property 1

Translation preserves

- Distance
- Angles
- Parallel Lines

---

### Property 2

No Rotation occurs.

---

### Property 3

No Reflection occurs.

---

### Property 4

The image and original are congruent.

---

### Property 5

Every point moves equally.

---

### 2. Left Means Subtract

```

### 3. Up Means Add

```

```

---

### 4. Down Means Subtract

```
-y

# Common Mistakes

### Mistake 1

Changing the size of the figure.

Translation never changes size.

---

### Mistake 2

Rotating instead of translating.

---

### Mistake 3

Applying different movements to different vertices.

Every point moves equally.

---

### Mistake 4

Confusing

```
Right

↓

+x

Left

↓

-x
```

---

### Mistake 5

Forgetting negative coordinates.

# GATE 80/20 Summary

✅ Translation only changes the **position** of a figure.

✅ Apply the **same vector** to every vertex.

✅ Remember:

- Right → +x
- Left → -x
- Up → +y
- Down → -y

✅ Use the formula:

```
(x, y)

↓

(x + a, y + b)
```

✅ Translation preserves **shape, size, angles, area, orientation, and distances**. Only the location changes.
