# Algebraic Structures

An **Algebraic Structure** consists of:

- A non-empty set
- One or more binary operations

Hierarchy

```
Algebraic Structures
│
├── Semigroup
│
├── Monoid
│
└── Group
     │
     └── Abelian Group
```

---

# Binary Operation

A binary operation combines two elements of a set to produce another element of the same set.

Definition

```
*: A × A → A
```

Example

```
+

on Integers
```

```
2 + 5 = 7
```

Since 7 is also an integer, it is a valid binary operation.

---

# Closure Property

A set is **closed** under an operation if performing the operation on any two elements always produces an element of the same set.

Example

```
Integers

under +

```

Closed because

```
5 + (-2) = 3
```

---

# Associative Property

Definition

```
(a*b)*c

=

a*(b*c)
```

Example

```
(2+3)+4

=

2+(3+4)
```

---

# Commutative Property

Definition

```
a*b

=

b*a
```

Example

```
2+5

=

5+2
```

---

# Identity Element

An element

```
e
```

such that

```
a*e

=

e*a

=

a
```

Example

Addition

```
0
```

because

```
5+0=5
```

Multiplication

```
1
```

because

```
5×1=5
```

Identity element is **unique**.

---

# Inverse Element

For every element

```
a
```

there exists

```
a⁻¹
```

such that

```
a*a⁻¹

=

e
```

Example

Addition

```
5

+

(-5)

=

0
```

---

# Semigroup

A **Semigroup** is a set with

- Closure
- Associativity

Definition

```
(Set, *)

↓

Closure

+

Associativity
```

Example

```
Positive Integers

under +

```

---

# Monoid

A **Monoid** is a Semigroup that also has an Identity Element.

Definition

```
Closure

+

Associativity

+

Identity
```

Memory Trick

```
Monoid

=

Semigroup

+

Identity
```

---

# Examples of Monoids

### Integers under Addition

Identity

```
0
```

✔ Monoid

---

### Natural Numbers under Multiplication

Identity

```
1
```

✔ Monoid

---

### Strings under Concatenation

Identity

```
""
```

(Empty String)

✔ Monoid

# Group

A **Group** is a Monoid in which every element has an inverse.

Definition

```
Closure

+

Associativity

+

Identity

+

Inverse
```

Memory Trick

```
Group

=

Monoid

+

Inverse
```

---

# Examples of Groups

### Integers under Addition

Identity

```
0
```

Inverse

```
-a
```

✔ Group

---

### Real Numbers (Except 0) under Multiplication

Identity

```
1
```

Inverse

```
1/a
```

✔ Group

---

### Natural Numbers under Addition

No inverse.

❌ Not a Group.

---

# Abelian Group (Commutative Group)

A Group that also satisfies

```
Commutativity
```

Definition

```
Closure

+

Associativity

+

Identity

+

Inverse

+

Commutativity
```

Memory Trick

```
Abelian

=

Group

+

Commutative
```

---

# Examples

### Integers under Addition

✔ Abelian Group

---

### Real Numbers under Addition

✔ Abelian Group

---

### Matrix Multiplication

Generally **not commutative**.

✔ Group (only for invertible matrices)

❌ Not Abelian

# Cayley Table

A table representing a binary operation.

Example

```
+

| + |0|1|
|---|--|--|
|0|0|1|
|1|1|2|
```

Used to verify

- Closure
- Identity
- Inverse

---

# Order of a Group

The number of elements in a group.

Notation

```
|G|
```

Example

```
G={0,1,2}

Order=3
```

---

# Order of an Element

Smallest positive integer

```
n
```

such that

```
aⁿ=e
```

Important for finite groups.

---

# Cyclic Group

A group generated by a single element.

Notation

```
<a>
```

Example

```
Z₆

generated by

1
```

---

# Generator

An element capable of generating the entire group.

---

# Subgroup

A subset of a group that is itself a group under the same operation.

Conditions

- Non-empty
- Closed
- Identity present
- Inverses present

---

# Important Theorems

Identity element is unique.

✔ True

---

Inverse of every element is unique.

✔ True

---

Every Group is a Monoid.

✔ True

---

Every Monoid is a Semigroup.

✔ True

---

Every Semigroup is a Group.

❌ False

---

Every Abelian Group is a Group.

✔ True

---

Every Group is Abelian.

❌ False
