# What is Discrete Mathematics?

Discrete Mathematics is the branch of mathematics that deals with **countable objects** instead of continuous values.

Unlike calculus, which studies continuous change, discrete mathematics studies structures like

- Logic
- Sets
- Graphs
- Trees
- Relations
- Counting
- Algebraic Structures

It forms the mathematical foundation of Computer Science.

---

# Why is it Important?

Almost every CS subject uses Discrete Mathematics.

| Subject | Uses |
|----------|------|
| Data Structures | Trees, Graphs |
| Algorithms | Recurrence, Graph Theory |
| Operating Systems | Graphs |
| DBMS | Relations |
| Compiler Design | Automata, Logic |
| AI | Logic |
| Cryptography | Groups |
| Networking | Graphs |
