# Why Should You Study ALU?

The Arithmetic Logic Unit (ALU) is the computational heart of the CPU.

Every arithmetic calculation, logical comparison, address calculation, and branch decision ultimately passes through the ALU.

Whenever your processor executes instructions such as

```
ADD

SUB

AND

OR

XOR

CMP

SHIFT

MULTIPLY

DIVIDE
```

the ALU performs the operation.

Without the ALU, a CPU cannot execute programs.

# What is an ALU?

The Arithmetic Logic Unit is the hardware block responsible for performing

- Arithmetic Operations
- Logical Operations
- Shift Operations
- Comparison Operations
- Address Calculations

The ALU **does not store data**.

It only processes data.

Data is stored in

- Registers
- Cache
- Main Memory

# Carry Flag (CF)

### Definition

Set when an unsigned arithmetic operation produces a carry (or borrow) beyond the most significant bit.

### Example

Using 8-bit arithmetic:

```
11111111
+00000001
----------
1 00000000
```

Stored result:

```
00000000
```

Carry Flag = 1

### Important

Carry Flag is mainly used for **unsigned arithmetic**.

---

# Zero Flag (ZF)

### Definition

Set if the ALU result is zero.

Example

```
15 - 15

↓

0
```

Zero Flag = 1

Used by instructions like

```
BEQ

JE

JZ
```

---

# Sign Flag (SF)

Represents the sign of the result.

Usually

```
MSB

↓

Sign Bit
```

If

```
MSB = 1
```

Result is negative (Two's Complement representation).

---

# Overflow Flag (OF)

One of the most important GATE topics.

Overflow occurs only in **signed arithmetic** when the mathematical result cannot be represented with the available number of bits.

### Overflow Rules

Positive + Positive → Negative

↓

Overflow

Negative + Negative → Positive

↓

Overflow

Otherwise

↓

No Overflow

### Example

8-bit numbers

```
01111111

+

00000001

↓

10000000
```

Actual result should be

```
128
```

But 8-bit signed range is

```
-128 to +127
```

Overflow occurs.

---

# Carry Flag vs Overflow Flag

| Carry Flag | Overflow Flag |
|------------|---------------|
|Unsigned Arithmetic|Signed Arithmetic|
|Checks Carry Out|Checks Invalid Signed Result|
|Depends on Carry|Depends on Sign Change|

⭐ One of the most frequently asked GATE comparisons.

---

# Ripple Carry Adder (RCA)

Constructed using multiple Full Adders.

```
FA → FA → FA → FA
```

### Working

Each Full Adder waits for the previous carry.

Carry propagates stage by stage.

### Advantages

- Simple
- Low hardware cost

### Disadvantages

- Slow
- Propagation delay increases with bit width

---

# Carry Look Ahead Adder (CLA)

Designed to eliminate ripple carry delay.

### Generate Signal

```
G = A × B
```

### Propagate Signal

```
P = A ⊕ B
```

Carry Equation

```
C(i+1)=Gi+PiCi
```

Advantages

- Faster
- Parallel carry computation

Disadvantages

- More hardware
- Higher complexity

---

# Booth Multiplication (Concept)

Used for efficient multiplication of signed binary numbers.

Advantages

- Fewer additions
- Handles negative numbers naturally
- Faster than repeated addition

**GATE generally asks the algorithm concept or a simple numerical.**

---

# Restoring Division (Concept)

Steps

1. Shift
2. Subtract Divisor
3. Check Sign
4. Restore if Negative
5. Repeat

---

# Non-Restoring Division (Concept)

Improves restoring division by avoiding the restore step in every iteration.

Advantages

- Faster
- Fewer operations

---

# Comparison Table

| Feature | RCA | CLA |
|----------|-----|-----|
|Speed|Slow|Fast|
|Hardware|Simple|Complex|
|Carry|Sequential|Parallel|
|Delay|High|Low|

# Interview Questions

### Q1. What is the difference between the Control Unit and the ALU?

**Answer:**

The Control Unit decides **what operation should be performed** by generating control signals, while the ALU actually performs arithmetic, logical, comparison, and address calculation operations.

---

### Q2. Why is an ALU called the computational unit of the CPU?

**Answer:**

Because every arithmetic calculation, logical operation, comparison, and address computation is executed by the ALU.

---

### Q3. Why is Carry Flag different from Overflow Flag?

**Answer:**

Carry Flag is meaningful for **unsigned arithmetic**, whereas Overflow Flag indicates an invalid result in **signed arithmetic**.

---

### Q4. Why is CLA preferred over RCA?

**Answer:**

CLA computes carry signals in parallel using Generate and Propagate logic, reducing propagation delay significantly compared to RCA.
