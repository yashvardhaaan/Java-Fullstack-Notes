# 05 — Network Types

## 1. Network Types

Networks can be classified mainly by **geographical coverage**.

```text
PAN → LAN → MAN → WAN
small ───────────────→ large
```

---

## 2. PAN — Personal Area Network

**Range:** Very small area around a person.

Examples:

* Bluetooth
* Personal devices
* Smartwatch ↔ Phone

```text
Watch ── Phone ── Earbuds
```

**Key:** Personal devices.

---

## 3. LAN — Local Area Network ⭐

Covers a **limited geographical area**.

Examples:

* Home
* Office
* Building
* College lab

Characteristics:

* High speed
* Low latency
* Usually privately owned

Examples of technologies:

* Ethernet
* Wi-Fi

**Key:**

> LAN = **small area + high speed**

---

## 4. MAN — Metropolitan Area Network

Covers a **city/metropolitan area**.

```text
Building A ──┐
Building B ──┼── City Network
Building C ──┘
```

Larger than LAN, smaller than WAN.

**Key:**

> MAN = **City**

---

## 5. WAN — Wide Area Network ⭐

Covers a **large geographical area**.

Examples:

* Country
* Continent
* Worldwide

```text
LAN ── Router ── WAN ── Router ── LAN
```

The **Internet** is the largest example of an interconnected network of networks.

**Key:**

> WAN = **Large geographical area**

---

# 🔥 Comparison

| Type    | Coverage      | Example              |
| ------- | ------------- | -------------------- |
| **PAN** | Person        | Bluetooth            |
| **LAN** | Building/home | Ethernet, Wi-Fi      |
| **MAN** | City          | Metropolitan network |
| **WAN** | Country/world | Internet             |

### Memory Trick

**P → L → M → W**

> **Person → Local → Metropolitan → Wide**

Area generally increases:

$$
PAN < LAN < MAN < WAN
$$

---

# 🧠 GATE Traps

### Trap 1

**LAN does NOT necessarily mean wired.**

Wi-Fi can be used to create a LAN.

### Trap 2

**WAN ≠ Internet**

WAN is a **type of network based on geographical scope**; the Internet is a global interconnected system of networks.

### Trap 3

Classification is primarily based on **geographical coverage**, not simply speed.
